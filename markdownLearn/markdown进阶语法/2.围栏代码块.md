# 二.围栏代码块

## 1.反引号代码块
```c
#include <stdio.h>
int main() 
{
    int a = 0;
    int b = 0;
    a = 10;             /*给a赋值
    b = 20;             给b赋值*/
    printf("a+b=%d\n", a + b);

    return 0;
}
```
