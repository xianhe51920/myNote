# JS 学习协作流程计划

## Summary

本计划定义用户与 AI 在 JavaScript 学习过程中的协作流程。用户观看 B 站黑马程序员课程，将知识点截图发送给 AI，由 AI 负责文件夹创建、截图归类命名以及 `javascript.md` 主文档的内容补充。

### 截图命名规则

- 每个章节文件夹内，截图按观看顺序命名为 `0.png`, `1.png`, `2.png`...
- 数字从 0 开始，连续递增
- 同一章节的截图集中在该章节文件夹下

## Proposed Workflow（未来协作流程）

### Step 1: 用户发送截图

用户将某章节的知识点截图直接发送给 AI，并告知所属章节（如"这是 JS基础第 3 章 常量"或"这是 APIs 第 15 章 节点操作"）。

### Step 2: AI 创建/确认文件夹

- 若该章节文件夹已存在，直接使用
- 若不存在，AI 按命名规范创建新文件夹：
  - `JS基础/` 下：`N.章节名/`（如 `11.新章节/`）
  - `APIS/` 下：`N.章节名/`（如 `21.新章节/`）

### Step 3: AI 命名归类截图

- 查看目标章节文件夹内现有截图的最大编号
- 将新截图按顺序命名为 `(max+1).png`, `(max+2).png`...
- 保存到对应章节文件夹

### Step 4: AI 阅读截图并补充文档

- 使用 Read 工具读取章节文件夹内所有截图
- 根据截图内容，在 `javascript.md` 中对应章节位置补充知识点
- 补充格式保持与现有文档一致：
  - 章节标题使用 `### N. 章节名`
  - 小节标题使用 `#### N.M 小节名`
  - 使用表格、代码块、Mermaid 图表等增强可读性
  - 关键概念加粗，代码标注语言标签

### Step 5: 更新知识树（按需）

- 如果新增章节或章节结构变化，同步更新 `js基础Mermaid.md` 或 `apisMermaid.md`
- 确保树状图节点 ID 与 `javascript.md` 中的 `#### N.M` 编号严格对应

## Assumptions & Decisions

1. **每次只整理特定章节**：用户每次只发送一个章节的截图，AI 只处理该章节，不跨章整理
2. **截图顺序即学习顺序**：用户发送截图的顺序即为命名序号顺序
3. **文档格式一致性**：补充内容时严格遵循 `javascript.md` 现有排版风格
4. **Mermaid 规范**：树状图中含特殊字符（如 `<br/>`、`=`）的节点必须用双引号包裹
5. **用户最终确认**：文档补充完成后由用户审阅，必要时再调整
