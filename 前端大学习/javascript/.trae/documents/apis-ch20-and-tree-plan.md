**内容大纲**（基于 0~25.png 截图整理）：

#### 20.1 什么是正则表达式
- 概念：用于匹配字符串中字符组合的**模式**（Regular Expression），在 JS 中正则表达式也是**对象**
- 三大使用场景：**表单验证**（匹配）/ **过滤敏感词**（替换）/ **提取字符串**（提取）
- 图示：人群匹配（找"戴帽子戴眼镜的男人"→ 把描述信息编码成模式）

#### 20.2 语法
- **两步法**：① 定义规则 ② 查找
- **定义正则表达式**：`const 变量名 = /表达式/`（`/` 是正则表达式字面量）
- **test() 方法**：`regObj.test(被检测的字符串)` → 返回 `true` / `false`
- **exec() 方法**：`regObj.exec(被检测字符串)` → 匹配成功返回**数组**（含 `index`、`input`、`groups`），否则返回 `null`
- **区别**：test 返回布尔值，exec 返回数组或 null
- 代码示例：检测字符串 `'IT培训，前端开发培训...'` 是否含 `'前端'`

#### 20.3 元字符
- **普通字符**：仅能描述自身（所有字母和数字）
- **元字符（特殊字符）**：具有特殊含义，提高灵活性（`[a-z]` 替代 `abcdefghijklm...`）
- **分类**：
  1. **边界符**（位置符）`^` 行首 / `$` 行尾 → 一起用表示精确匹配
  2. **量词**（重复次数）`*` / `+` / `?` / `{n}` / `{n,}` / `{n,m}`（注意逗号左右无空格）
  3. **字符类**：`[abc]` 字符集合 / `[a-z]` 连字符范围 / `[^a-z]` 取反 / `.` 除换行外任意字符
  4. **预定义类**：`\d`（0-9）/ `\D`（非 0-9）/ `\w`（字母数字下划线）/ `\W`（非 \w）/ `\s`（空白）/ `\S`（非空白）
- 日期格式示例：`^\d{4}-\d{1,2}-\d{1,2}$`
- QQ 号示例：`^[1-9][0-9]{4,}$`（10000+）

#### 20.4 修饰符
- **作用**：约束正则执行的细节行为（大小写、多行匹配）
- **语法**：`/表达式/修饰符`
- **`i`**（ignore）：匹配时不区分大小写
- **`g`**（global）：全局匹配所有满足的结果
- 代码示例：`/a/i.test('A')` → `true`

#### 20.5 replace 替换
- **语法**：`字符串.replace(/正则表达式/, '替换的文本')`

#### 20.6 本章总结（表格）
| 类别 | 符号/方法 | 作用 |
|---|---|---|
| 定义 | `/表达式/` | 正则字面量 |
| 检测 | `test()` | 返回布尔值 |
| 检索 | `exec()` | 返回数组或 null |
| 边界符 | `^` `$` | 行首/行尾 |
| 量词 | `* + ? {n} {n,} {n,m}` | 重复次数 |
| 字符类 | `[abc] [a-z] [^a-z]` | 集合/范围/取反 |
| 预定义类 | `\d \D \w \W \s \S` | 常用简写 |
| 修饰符 | `i g` | 大小写/全局 |
| 替换 | `str.replace(/正则/, text)` | 字符串替换 |
