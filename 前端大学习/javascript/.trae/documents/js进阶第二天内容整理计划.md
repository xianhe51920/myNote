  - `new Array(3, 5)` 创建数组（不推荐字面量）
  - **核心方法 4 选 1**（已经在 3.解构赋值 介绍过 forEach/filter，但本章 PPT 重新强调）：
    - forEach：遍历，不返回数组
    - filter：过滤，返回新数组
    - map：迭代，返回新数组
    - reduce：累计，返回累计结果
  - **reduce 详解**（11.png、12.png 重点内容）：
    - 语法 `arr.reduce(function(上一次值, 当前值){}, 初始值)`
    - 执行过程 3 步（无起始值时 / 每次循环 / 有起始值时）
  - `Array.from(伪数组)`：伪数组转真数组
  - **其他方法（13.png 需要补全示例）**：
    | 方法 | 作用 | 示例 |
    | join | 数组元素拼接为字符串 | `[1,2,3].join('-')` → `'1-2-3'` |
    | find | 查找第一个符合条件的元素 | `[10,20,30].find(v=>v>15)` → `20` |
    | every | 检测所有元素是否都符合 | `[1,3,5].every(v=>v%2)` → `true` |
    | some | 检测是否有元素符合 | `[1,2,3].some(v=>v>2)` → `true` |
    | concat | 合并两个数组 | `[1,2].concat([3,4])` → `[1,2,3,4]` |
    | sort | 对原数组单元值排序 | `[3,1,2].sort()` → `[1,2,3]` |
    | splice | 删除或替换数组单元 | `[1,2,3].splice(1,1)` → 返回 `[2]`，数组变 `[1,3]` |
    | reverse | 反转数组 | `[1,2,3].reverse()` → `[3,2,1]` |
    | findIndex | 查找元素的索引值 | `[10,20,30].findIndex(v=>v>15)` → `1` |
