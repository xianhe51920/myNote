  - 排序：`sort`、`reverse`
- 8.4 数组案例
  - 数组求和 / 平均值
  - 数组最大值 / 最小值
  - 数组筛选（满足条件的元素）

  - 函数命名规范（动词）
- 9.3 函数传参
  - 形参 vs 实参
  - 默认值参数
  - 伪数组 `arguments`
- 9.4 函数返回值
  - `return` 关键字
  - 没有 return 返回 `undefined`
  - return 之后的代码不执行
  - return 只能返回一个值（多个用数组/对象）
- 9.5 作用域
  - 全局作用域 vs 局部作用域
  - 块级作用域（`let` / `const`）
  - 作用域链（用 Mermaid `flowchart LR` 描述链式查找）
  - 变量访问原则：就近原则
- 9.6 匿名函数
  - 函数表达式 `const fn = function() {}`
  - 立即执行函数 IIFE
  - 回调函数
