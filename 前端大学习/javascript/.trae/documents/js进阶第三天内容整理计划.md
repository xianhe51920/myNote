### 变更 3：在 `javascript.md` 追加 `### 8. 原型`

**位置**：`#### 7.4` 之后

**结构**：
- 引子（> 章节涵盖：原型 / constructor 属性 / 对象原型 / 原型继承 / 原型链 / instanceof）
- Mermaid 总览图
- `#### 8.1 原型（prototype）`
  - 构造函数通过原型分配的函数是所有对象共享的
  - `prototype` 是什么？JS 规定每个构造函数都有一个 prototype 属性，指向另一个对象，所以也称为原型对象
  - 这个对象可以挂载函数，对象实例化不会多次创建原型上函数，节约内存
  - 可以把那些不变的方法直接定义在 prototype 对象上，所有对象实例就能共享
  - 代码示例：Star.prototype.sing
  - **this 指向**：构造函数和原型对象中的 this 都指向实例化的对象（8.2 内容提前在这里简要提示）
- `#### 8.2 constructor 属性`
  - 在哪里？每个原型对象里面都有一个 constructor 属性（constructor 构造函数）
  - 作用：该属性指向该原型对象的构造函数（指回爸爸）
  - 使用场景：当用对象形式赋值（`Star.prototype = { ... }`）会覆盖原型对象，需要手动加 `constructor: Star`
- `#### 8.3 对象原型（`__proto__`）`
  - 实例对象都有一个属性 `__proto__` 指向构造函数的 prototype 原型对象
  - **注意**：
    - `__proto__` 是 JS 非标准属性
    - `[[prototype]]` 和 `__proto__` 意义相同
    - 用来表明当前实例对象指向哪个原型对象 prototype
    - `__proto__` 对象原型里也有一个 constructor 属性，指向创建该实例对象的构造函数
  - 关系图（Mermaid）：构造函数 → prototype ↔ 实例对象 → `__proto__`
- `#### 8.4 原型继承`
  - 概念：JS 中大多是借助原型对象实现继承的特性
  - 问题：Man / Woman 构造函数有大量重复代码
  - **封装抽取公共部分**：抽出 People 公共对象（head/eyes/legs/say/eat）
  - **问题--原因**：`Man.prototype = People` 和 `Woman.prototype = People` 都指向**同一个对象**，修改一个会影响另一个
  - **解决**：构造函数（每次 new 都创建一个新对象）
  - 解决代码示例：用构造函数封装 People，Man/Woman 继承之
- `#### 8.5 原型链-查找规则`
  - 6 条规则：
    1. 访问对象属性/方法时，先查找对象自身有没有
    2. 没有就查找它的原型（`__proto__` 指向的 prototype）
    3. 还没有就查找原型对象的原型（Object 的原型对象）
    4. 依次类推一直找到 Object 为止（null）
    5. `__proto__` 对象原型的意义在于为对象成员查找机制提供一个方向，或者说一条路线
    6. `instanceof` 运算符用于检测构造函数的 prototype 属性是否出现在某个实例对象的原型链上
- `#### 8.6 instanceof 运算符`
  - 描述：用来检测 `constructor.prototype` 是否存在于参数 object 的原型链上
  - MDN 风格代码示例（C/D/Object 三个构造函数 + instanceof 检查）
- `#### 8.7 本章总结`：表格
