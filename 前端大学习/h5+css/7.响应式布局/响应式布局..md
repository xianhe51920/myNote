# 响应式布局
- 媒体查询
- BootStrap响应式

**响应式布局**是一种网页设计方法是，使网页能够根据**用户设备的屏幕尺寸，分辨率，方向（横屏/书评）等特性**自动调整布局和内容**，提供一致且优化的用户体验。其核心目标是“一次设计，多端适配”

| 优点 | 缺点 |
| :--- | :--- |
| 1. 一套代码适配多端设备 | 1. 复杂布局需较多调试 |
| 2. 节省开发和维护成本 | 2. 过度使用媒体查询可能影响性能 |
| 3. 用户体验一致性高 | 3. 需精准计算断点（什么屏幕下，怎么显示） |


---

**响应式布局核心技术**  
**布局方式**  
- 弹性盒子（Flexbox）
- 网格布局（CSS Grid）
- 百分比布局（流式布局）
- 单位可借助 `vw` 实现

**断点（Breakpoints）设置**
- 根据常见设备宽度设置断点
  - 手机：`< 768px`
  - 平板：`768px ~ 1024px`
  - PC：`> 1024px`
- 根据不同设备宽度显示不同布局样式

| 断点名称 | 最小宽度 | CSS 媒体查询 | 适用场景 |
| :--- | :--- | :--- | :--- |
| xs | <576px | `@media (min-width: 0)` | 超小设备（手机竖屏） |
| sm | ≥576px | `@media (min-width: 576px)` | 平板竖屏/小屏手机横屏 |
| md | ≥768px | `@media (min-width: 768px)` | 平板横屏/桌面小屏 |
| lg | ≥992px | `@media (min-width: 992px)` | 桌面中屏 |
| xl | ≥1200px | `@media (min-width: 1200px)` | 桌面大屏 |
| xxl | ≥1400px | `@media (min-width: 1400px)` | 超宽屏（4K 显示器等） |

---

**响应式布局实现方案**  
1.  **媒体查询**
    媒体查询是 CSS3 的功能，允许根据设备的特性（如屏幕宽度、高度、分辨率、设备类型等）应用不同的样式规则。它是实现响应式设计的核心技术。

2.  **第三方框架 Bootstrap**
    预置样式和组件减少重复编码，缩短项目周期，适配 PC、移动端及主流浏览器。后续还可以学习其他不同的框架。



## 媒体查询

### 1. 基本语法

```css
/* 方式一：@media规则 */
@media 媒体类型 and (媒体特性) {
    /* CSS样式 */
}

/* 方式二：在link标签中引入 */
<link media="媒体类型 and (媒体特性)" href="styles.css">

/* 方式三：在CSS中使用@import */
@import url("styles.css") 媒体类型 and (媒体特性);
```

### 2. 媒体类型

| 媒体类型 | 说明 | 常用场景 |
| :--- | :--- | :--- |
| `screen` | 屏幕设备 | 网页显示（最常用） |
| `print` | 打印设备 | 打印机、打印预览 |
| `all` | 所有设备 | 默认值 |
| `speech` | 语音合成器 | 屏幕阅读器 |
| `tv` | 电视设备 | 智能电视 |

### 3. 媒体特性

| 媒体特性 | 说明 | 示例 |
| :--- | :--- | :--- |
| `width` | 视口宽度 | `@media (width: 768px)` |
| `height` | 视口高度 | `@media (height: 1024px)` |
| `min-width` | 最小宽度（及以上） | `@media (min-width: 768px)` |
| `max-width` | 最大宽度（及以下） | `@media (max-width: 1200px)` |
| `min-height` | 最小高度 | `@media (min-height: 600px)` |
| `max-height` | 最大高度 | `@media (max-height: 800px)` |
| `orientation` | 屏幕方向 | `@media (orientation: landscape)` |
| `aspect-ratio` | 宽高比 | `@media (aspect-ratio: 16/9)` |

### 4. 逻辑运算符

```css
/* and：同时满足多个条件 */
@media screen and (min-width: 768px) and (max-width: 1024px) {
    /* 平板设备 */
}

/* not：对整个媒体查询取反 */
@media not screen {
    /* 非屏幕设备 */
}

/* only：仅在指定媒体类型生效 */
@media only screen {
    /* 仅屏幕设备 */
}

/* 逗号（或）：满足任一条件 */
@media (min-width: 768px), (orientation: landscape) {
    /* 宽度≥768px 或 横屏 */
}
```

### 5. 常见使用场景

#### 场景一：根据屏幕宽度改变布局

```css
/* 默认样式（移动端） */
.container {
    width: 100%;
    padding: 10px;
}

/* 平板及以上设备 */
@media (min-width: 768px) {
    .container {
        width: 750px;
        padding: 20px;
    }
}

/* 桌面及以上设备 */
@media (min-width: 992px) {
    .container {
        width: 970px;
        padding: 30px;
    }
}

/* 大屏幕设备 */
@media (min-width: 1200px) {
    .container {
        width: 1170px;
        padding: 40px;
    }
}
```

#### 场景二：隐藏/显示元素

```css
/* 默认显示 */
.sidebar {
    display: block;
}

/* 小屏幕隐藏侧边栏 */
@media (max-width: 768px) {
    .sidebar {
        display: none;
    }
}
```

#### 场景三：横屏/竖屏适配

```css
/* 横屏模式 */
@media (orientation: landscape) {
    .container {
        flex-direction: row;
    }
}

/* 竖屏模式 */
@media (orientation: portrait) {
    .container {
        flex-direction: column;
    }
}
```

#### 场景四：Retina屏幕高清显示

```css
/* 普通屏幕 */
.logo {
    background-image: url("logo.png");
}

/* Retina屏幕（2倍密度） */
@media (-webkit-min-device-pixel-ratio: 2), (min-resolution: 192dpi) {
    .logo {
        background-image: url("logo@2x.png");
    }
}
```

### 6. 移动优先 vs 桌面优先

#### 移动优先（推荐）

```css
/* 1. 先编写移动端基础样式 */
.box {
    width: 100%;
    font-size: 14px;
}

/* 2. 逐步添加更大屏幕的样式 */
@media (min-width: 768px) {
    .box {
        width: 50%;
        font-size: 16px;
    }
}

@media (min-width: 1200px) {
    .box {
        width: 33.33%;
        font-size: 18px;
    }
}
```

#### 桌面优先

```css
/* 1. 先编写桌面端样式 */
.box {
    width: 33.33%;
    font-size: 18px;
}

/* 2. 逐步添加小屏幕的样式 */
@media (max-width: 1199px) {
    .box {
        width: 50%;
        font-size: 16px;
    }
}

@media (max-width: 767px) {
    .box {
        width: 100%;
        font-size: 14px;
    }
}
```

### 7. 最佳实践

#### 断点设置建议

```css
/* 超小屏幕（手机竖屏）<576px */
/* 小屏幕（手机横屏/小平板）576px-767px */
/* 中等屏幕（平板）768px-991px */
/* 大屏幕（桌面）992px-1199px */
/* 超大屏幕（桌面大屏）≥1200px */
```

#### 实用技巧

```css
/* 1. 使用min-width而不是精确值 */
@media (min-width: 768px) { /* ✓ 好 */ }
@media (width: 768px) { /* ✗ 差：768px的设备很少 */ }

/* 2. 合理控制媒体查询数量 */
@media (min-width: 576px) { /* 小屏平板 */ }
@media (min-width: 768px) { /* 平板 */ }
@media (min-width: 992px) { /* 桌面 */ }
@media (min-width: 1200px) { /* 大屏桌面 */ }

/* 3. 使用CSS变量管理断点 */
:root {
    --breakpoint-sm: 576px;
    --breakpoint-md: 768px;
    --breakpoint-lg: 992px;
    --breakpoint-xl: 1200px;
}

/* 4. 配合flex和grid使用 */
.grid {
    display: grid;
    grid-template-columns: 1fr;
}

@media (min-width: 768px) {
    .grid {
        grid-template-columns: repeat(2, 1fr);
    }
}

@media (min-width: 1200px) {
    .grid {
        grid-template-columns: repeat(4, 1fr);
    }
}
```

| 功能 | Chrome | Firefox | Safari | Edge | IE |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 基础媒体查询 | 1+ | 1+ | 1+ | 12+ | 9+ |
| min/max前缀 | 1+ | 1+ | 1+ | 12+ | 9+ |
| orientation | 3+ | 6+ | 5+ | 12+ | 9+ |
| aspect-ratio | 3+ | 6+ | 5+ | 12+ | ✗ |

### 9. 常见错误避免

```css
/* ✗ 错误1：媒体查询位置不当 */
/* 媒体查询应该放在样式规则之后 */
.box { color: red; }
@media (min-width: 768px) { .box { color: blue; } }

/* ✗ 错误2：断点重叠 */
@media (min-width: 768px) { .box { width: 750px; } }
@media (min-width: 750px) { .box { width: 970px; } } /* 750px处重叠 */

/* ✓ 正确：断点保持合理间距 */
@media (min-width: 768px) { .box { width: 750px; } }
@media (min-width: 992px) { .box { width: 970px; } }

/* ✗ 错误3：单位混淆 */
@media (min-width: 768) { /* ✗ 缺少单位 */ }
@media (min-width: 768px) { /* ✓ 正确 */ }

/* ✗ 错误4：媒体特性拼写错误 */
@media (min-width: 768px) and (max-with: 1200px) { /* ✗ max-with */ }
@media (min-width: 768px) and (max-width: 1200px) { /* ✓ max-width */ }
```

## BootStrap响应式

### BootStrap框架介绍和引用

**什么是Bootstrap**

Bootstrap 是由 Twitter 公司开发维护的一套**前端UI框架**，它提供了一套现成的CSS样式和组件，开发者可以直接引用这些类名，快速搭建响应式网页。

**Bootstrap优势**

| 优势 | 说明 |
| :--- | :--- |
| 响应式设计 | 一套代码适配手机、平板、PC等多端设备 |
| 标准化 | 提供统一的视觉风格和组件规范 |
| 开发效率高 | 大量预置样式和组件，无需从零写CSS |
| 跨浏览器兼容 | 兼容主流浏览器，减少兼容性调试 |
| 可定制 | 支持按需定制，也可以覆盖默认样式 |

**Bootstrap版本**

| 版本 | 特点 | 适用场景 |
| :--- | :--- | :--- |
| Bootstrap 3 | 经典稳定，支持IE8+，国内网课最常用 | 学习入门、传统项目 |
| Bootstrap 4 | 引入Flexbox，移除IE支持，新增卡片等组件 | 现代项目 |
| Bootstrap 5 | 移除jQuery依赖，新增RTL支持，纯CSS组件 | 新项目推荐 |

**引入方式**

方式一：CDN引入（推荐学习时使用）

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="utf-8">
    <!-- 必须配置viewport，否则响应式无效 -->
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>Bootstrap示例</title>
    <!-- Bootstrap核心CSS -->
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@3.4.1/dist/css/bootstrap.min.css" rel="stylesheet">
    <!-- jQuery（Bootstrap3的JS依赖jQuery） -->
    <script src="https://cdn.jsdelivr.net/npm/jquery@1.12.4/dist/jquery.min.js"></script>
    <!-- Bootstrap核心JS -->
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@3.4.1/dist/js/bootstrap.min.js"></script>
</head>
<body>
    <!-- 页面内容 -->
</body>
</html>
```

方式二：本地引入

1. 下载Bootstrap压缩包并解压
2. 将css、js、fonts文件夹复制到项目中
3. 在HTML中引入本地文件

```html
<link rel="stylesheet" href="bootstrap/css/bootstrap.min.css">
<script src="bootstrap/js/jquery.min.js"></script>
<script src="bootstrap/js/bootstrap.min.js"></script>
```

**注意事项**：
- `viewport` meta标签是响应式的必要条件，必须添加
- Bootstrap 3的JS插件依赖jQuery，需要先引入jQuery
- 引入顺序：先CSS，再jQuery，最后Bootstrap JS

### BootStrap框架基本使用

**容器（Container）**

Bootstrap需要一个容器来包裹页面内容，提供两种容器类：

| 容器类 | 特点 | 适用场景 |
| :--- | :--- | :--- |
| `.container` | 固定宽度，居中显示，两侧留白 | PC端页面、常规布局 |
| `.container-fluid` | 100%宽度，充满视口 | 全屏布局、移动端 |

```html
<!-- 固定宽度容器 -->
<div class="container">
  <h1>固定宽度容器</h1>
  <p>在不同屏幕尺寸下有不同的固定宽度，并居中显示</p>
</div>

<!-- 全屏宽度容器 -->
<div class="container-fluid">
  <h1>全屏宽度容器</h1>
  <p>始终占满整个屏幕宽度</p>
</div>
```

.container在不同断点下的宽度：

| 屏幕尺寸 | 断点宽度 | container宽度 |
| :--- | :--- | :--- |
| 超小屏（手机） | <768px | 100% |
| 小屏（平板） | ≥768px | 750px |
| 中屏（桌面） | ≥992px | 970px |
| 大屏（大桌面） | ≥1200px | 1170px |

### BootStrap栅格布局

**栅格系统简介**

Bootstrap的栅格系统（Grid System）是一套**响应式、移动设备优先**的流式栅格布局系统。它将页面容器平均划分为**12列**，通过给列添加类名来控制元素在不同屏幕下的宽度。

**栅格系统工作原理**

```
┌──────────────────────────────────────────┐
│              container                   │
│  ┌───────────────────────────────────┐   │
│  │            row (12列)             │   │
│  ├─────┬─────┬─────┬─────┬─────┬─────┤   │
│  │col- │col- │col- │col- │col- │col- │   │
│  │ md-2│ md-2│ md-2│ md-2│ md-2│ md-2│   │
│  └─────┴─────┴─────┴─────┴─────┴─────┘   │
└──────────────────────────────────────────┘
```

核心要点：
1. **行（row）必须放在container中**
2. **列（col）必须作为row的直接子元素**
3. **内容应该放在列（col）中**
4. **每行12列**，列数之和超过12会自动换行

**栅格参数（断点）**

|  | 超小屏 <br>手机 (<768px) | 小屏 <br>平板 (≥768px) | 中屏 <br>桌面 (≥992px) | 大屏 <br>大桌面 (≥1200px) |
| :--- | :--- | :--- | :--- | :--- |
| **类名前缀** | `.col-xs-*` | `.col-sm-*` | `.col-md-*` | `.col-lg-*` |
| **列数** | 12 | 12 | 12 | 12 |
| **最大列宽** | 自动 | ~62px | ~81px | ~97px |
| **间距(gutter)** | 30px（左右各15px） | 30px | 30px | 30px |
| **是否浮动** | 是 | 是 | 是 | 是 |

**基础用法**

示例1：等宽列（三列布局）

```html
<div class="container">
  <div class="row">
    <div class="col-md-4">第一列（占4列，4/12 = 1/3）</div>
    <div class="col-md-4">第二列（占4列）</div>
    <div class="col-md-4">第三列（占4列）</div>
  </div>
</div>
```

示例2：不等宽列（侧边栏+主内容）

```html
<div class="container">
  <div class="row">
    <div class="col-md-3">侧边栏（占3列）</div>
    <div class="col-md-9">主内容区（占9列）</div>
  </div>
</div>
```

示例3：移动端和桌面端不同布局

```html
<div class="container">
  <div class="row">
    <!-- 手机：12列（满宽），平板/桌面：6列（半宽） -->
    <div class="col-xs-12 col-md-6">左侧内容</div>
    <!-- 手机：12列（满宽），平板/桌面：6列（半宽） -->
    <div class="col-xs-12 col-md-6">右侧内容</div>
  </div>
</div>
```

列组合示例代码（带颜色区分）：

```html
<style>
  .row > div {
    height: 50px;
    background-color: pink;
```

**列偏移（列与列之间的距离）**

使用 `.col-md-offset-*` 类可以将列向右偏移*个列宽：

```html

    <div class="col-md-4 col-md-offset-3">

    </div>
  </div>

  <div class="row">
    <div class="col-md-3">左侧</div>
    <div class="col-md-3 col-md-offset-6">右侧（偏移6列靠右）</div>
  </div>
  
  <!-- 居中显示 -->
  <div class="row">
    <!-- 占6列，偏移3列，实现居中（(12-6)/2=3） -->
    <div class="col-md-6 col-md-offset-3">
      这个div水平居中
    </div>
  </div>
</div>
```

常用的offset组合：

| 需求 | 类名 |
| :--- | :--- |
| 列居中（占6列） | `col-md-6 col-md-offset-3` |
| 列居中（占4列） | `col-md-4 col-md-offset-4` |
| 列居中（占8列） | `col-md-8 col-md-offset-2` |
| 两列两端对齐 | `col-md-3` + `col-md-3 col-md-offset-6` |

### svg裁剪背景
有时候，想要裁剪更复杂的形状，但是clip-path只能裁剪矩形。这时候，可以使用svg的clip-path属性来裁剪更复杂的形状。

**示例**

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>SVG裁剪背景示例</title>
    <style>
        /* 定义SVG裁剪路径 */
        .clip-svg {
            clip-path: url(#myClip);
        }

        /* 被裁剪的元素 */
        .clipped-element {
            width: 400px;
            height: 300px;
            background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
            clip-path: url(#myClip);
        }

        /* 对比：不裁剪的元素 */
        .normal-element {
            width: 400px;
            height: 300px;
            background: linear-gradient(135deg, #f093fb 0%, #f5576c 100%);
            margin-top: 20px;
        }
    </style>
</head>
<body>
    <!-- 定义SVG裁剪路径 -->
    <svg width="0" height="0">
        <defs>
            <!-- 复杂形状裁剪路径：波浪形 -->
            <clipPath id="myClip">
                <path d="M0,50 Q100,0 200,50 T400,50 L400,300 L0,300 Z" />
            </clipPath>
            
            <!-- 其他裁剪路径示例 -->
            <!-- 圆形裁剪 -->
            <clipPath id="circleClip">
                <circle cx="200" cy="150" r="100" />
            </clipPath>
            
            <!-- 多边形裁剪（六边形） -->
            <clipPath id="hexagonClip">
                <polygon points="200,0 400,75 400,225 200,300 0,225 0,75" />
            </clipPath>
            
            <!-- 文字裁剪 -->
            <clipPath id="textClip">
                <text x="50" y="150" font-size="60" font-weight="bold">HELLO</text>
            </clipPath>
        </defs>
    </svg>

    <!-- 使用裁剪路径的元素 -->
    <h3>使用SVG裁剪路径的元素（波浪形状）：</h3>
    <div class="clipped-element"></div>

    <h3>对比：不裁剪的元素：</h3>
    <div class="normal-element"></div>

    <!-- 其他裁剪形状示例 -->
    <h3>圆形裁剪：</h3>
    <div style="width: 400px; height: 300px; background: linear-gradient(45deg, #FF6B6B, #4ECDC4); clip-path: url(#circleClip);"></div>

    <h3>六边形裁剪：</h3>
    <div style="width: 400px; height: 300px; background: linear-gradient(45deg, #45B7D1, #96CEB4); clip-path: url(#hexagonClip);"></div>

    <h3>文字裁剪：</h3>
    <div style="width: 400px; height: 300px; background: url('https://picsum.photos/400/300') center/cover; clip-path: url(#textClip);"></div>
</body>
</html>
```

**关键要点：**

1. **SVG定义**：在HTML中定义SVG的`<defs>`标签，包含各种`<clipPath>`元素
2. **裁剪路径ID**：每个`<clipPath>`需要一个唯一的ID，如`id="myClip"`
3. **CSS引用**：在CSS中使用`clip-path: url(#myClip)`引用SVG裁剪路径
4. **复杂形状**：SVG裁剪路径可以创建任意复杂的形状，如波浪、多边形、文字等

**SVG裁剪路径类型对比：**

| 裁剪类型 | SVG元素 | 适用场景 | 复杂度 |
| :--- | :--- | :--- | :--- |
| 简单形状 | `<circle>`、`<rect>` | 圆形、矩形裁剪 | 低 |
| 多边形 | `<polygon>` | 星形、六边形等 | 中 |
| 自定义路径 | `<path>` | 波浪、复杂曲线 | 高 |
| 文字裁剪 | `<text>` | 文字形状背景 | 高 |

**与CSS clip-path对比：**

| 特性 | CSS clip-path | SVG clip-path |
| :--- | :--- | :--- |
| 基础形状 | 支持（circle、polygon等） | 支持 |
| 复杂路径 | 不支持 | ✓ 支持 |
| 文字裁剪 | 不支持 | ✓ 支持 |
| 动画支持 | ✓ 支持 | ✓ 支持 |
| 浏览器兼容 | 较好 | 略差（IE不支持） |

**实用技巧：**

```css
/* 1. 响应式裁剪 */
.clipped-responsive {
    clip-path: url(#responsiveClip);
}

/* 2. 动画裁剪 */
.clipped-animated {
    clip-path: url(#animatedClip);
    animation: clip-animation 3s infinite;
}

@keyframes clip-animation {
    0% { clip-path: url(#clip1); }
    50% { clip-path: url(#clip2); }
    100% { clip-path: url(#clip1); }
}

/* 3. hover效果 */
.clipped-hover {
    clip-path: url(#normalClip);
    transition: clip-path 0.3s ease;
}

.clipped-hover:hover {
    clip-path: url(#hoverClip);
}
```

**注意事项：**

- SVG裁剪路径需要在HTML中定义，不能在CSS中直接创建
- 裁剪路径的坐标系相对于被裁剪元素的左上角（0,0）
- 被裁剪的部分会完全隐藏，不显示任何内容
- SVG裁剪路径支持动画和过渡效果
- 浏览器兼容性：IE不支持，Edge12+支持

### TDK网站优化标签

TDK是 **Title**、**Description** 和 **Keywords** 三个元标签的缩写，它们是网站SEO优化的核心元素，直接影响搜索引擎对网页的理解和排名。

| 标签 | 作用 |
|------|------|
| **Title** | 决定搜索结果的标题显示，是搜索引擎判断页面主题的首要依据 |
| **Description** | 生成搜索结果的摘要描述，影响用户点击率（CTR） |
| **Keywords** | 提供页面主题关键词（尽管现代搜索引擎已弱化其权重，仍部分参考） |

三者共同构成网页的"第一印象"，优化不当可能导致排名下降或点击流失。

**代码示例：**

```html
<title>vivo智能手机官方网站 - X200s 影像旗舰</title>

<meta name="keywords" content="vivo, vivo官网, vivo智能手机大全, vivo手机最新报价, vivo手机图片, X200系列, S20系列, X Fold3, vivo Pad5 Pro, vivo WATCH 5, iQOO 13">

<meta name="description" content="手机领域的国际化品牌，vivo官网提供手机资讯、售前咨询、在线购买、售后服务等功能；vivo当季明星...">
```

> **提示**：国内几乎每个网站都会有这三大标签，是SEO优化的基础。
