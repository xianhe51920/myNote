# myNote 个人学习笔记仓库

> 本仓库用于统一管理个人在编程学习、课程备考、前端开发等多个领域的学习笔记与练习代码。

## 目录速查

| 目录 | 方向 | 主要内容 |
| :--- | :--- | :--- |
| `cLearn/` | C 语言 | 基础语法、练习代码、笔记整合 |
| `javaLearn/` | Java | 核心语法、练习代码、AI 开发相关课程笔记 |
| `markdownLearn/` | Markdown | 基本语法、进阶语法、变通写法、综合教程 |
| `前端大学习/` | 前端 | HTML / CSS / JavaScript 学习文档与练习 |
| `大学生期末杂项备考/` | 期末复习 | 高数、线代、概率论、大学物理等科目要点 |

## 模块说明

### cLearn
C 语言学习记录。`C语言.md` 汇总了所有章节笔记，`cCode/` 存放练习代码与 `CMakeLists.txt` 构建配置。

### javaLearn
Java 学习记录，分为三类内容：
- `Java笔记/`：按课程整理的纯文字笔记（`1.Java核心与AI开发基础.md`、`2.Java核心与AI开发进阶.md`）
- `JavaPractise/`：日常练习代码，按日期与主题分目录
- `截图/`：网课截图原始素材，按课程和章节组织，由 agent 整理到对应 md

### markdownLearn
Markdown 语法学习的全部笔记，分为「基本语法」「进阶语法」「变通」三个子目录，外加一份综合教程。

### 前端大学习
前端三件套（HTML / CSS / JavaScript）的学习记录：
- `h5+css/`：pink2025 课程的 HTML / CSS / 布局 / 动效 / 移动端 / 响应式 / 托管等专题
- `javascript/`：JS 基础与进阶笔记、配套 Mermaid 思维导图、`z练习/` 实战案例
- `前端常用文件/`：第三方库与工具文件（Bootstrap、Normalize.css、lodash 等）

### 大学生期末杂项备考
按学年与科目组织的复习资料：
- `大一/`：高数（上）、大学物理（B1）、线性代数
- `大二/`：概率论与数理统计

## 使用建议

- **编辑工具**：推荐使用 Typora / VS Code 打开 md 文件，可获得最佳渲染效果
- **忽略规则**：`.gitignore` 已配置忽略所有图片、视频、音频、构建产物、IDE 配置等，避免仓库体积膨胀
- **素材流转**：网课截图统一保存到 `javaLearn/截图/<课程>/<章节>/`，由 agent 整理到对应课程 md 中（纯文字，不嵌入图片）

本仓库为个人学习记录，如需引用内容请注明来源。
