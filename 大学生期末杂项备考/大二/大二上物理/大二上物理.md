### 1. 认识简谐运动

弹簧振子在水平方向上做往复运动，速度在两端最大位移处为零（$v=0$），在平衡位置处最大。可用旋转矢量法直观表示。

<img src="assets/1-1-弹簧振子运动.svg" alt="弹簧振子多帧运动示意" style="width:30vw;display:block;margin:0 auto;"/>



简谐运动的基本公式：

| 物理量 | 表达式 | 说明 |
| --- | --- | --- |
| 运动方程 | $x = A\cos(\omega t + \varphi_0)$ | |
| 振幅 | $A = \sqrt{x_0^2 + \dfrac{v_0^2}{\omega^2}}$ | 由初始条件决定 |
| 角频率 | $\omega = \sqrt{\dfrac{k}{m}} = \dfrac{2\pi}{T}$ | 弹簧振子 |
| 初相 | $\varphi_0$ | 由初始条件决定 |
| 相位 | $\omega t + \varphi_0$ | |
| 周期 | $T = \dfrac{2\pi}{\omega}$ | |
| 频率 | $\nu = \dfrac{1}{T} = \dfrac{\omega}{2\pi}$ | |
| 速度 | $v = \dfrac{dx}{dt} = -A\omega\sin(\omega t + \varphi_0)$，$v_{\max} = A\omega$ | |
| 加速度 | $a = \dfrac{dv}{dt} = -A\omega^2\cos(\omega t + \varphi_0)$，$a_{\max} = A\omega^2$ | |

> [!tip] 旋转矢量法
> 用一个长度为 $A$ 的旋转矢量以角速度 $\omega$ 逆时针旋转，矢量在 $x$ 轴上的投影即对应位移 $x$。矢量与 $x$ 轴的夹角即为相位 $\omega t + \varphi_0$，$t=0$ 时的夹角为初相 $\varphi_0$。
>
> <img src="assets/1-1-旋转矢量法.svg" alt="旋转矢量法示意" style="width:30vw;"/>


> [!tip] 弹簧串并联
> 弹簧串联：$\dfrac{1}{k} = \dfrac{1}{k_1} + \dfrac{1}{k_2}$
> 弹簧并联：$k = k_1 + k_2$
>
> <img src="assets/1-3-弹簧串并联.svg" alt="弹簧串并联模型" style="width:30vw;"/>

**题1.** 一质点按如下规律沿 $x$ 轴作简谐运动：$x = 0.1\cos\left(8\pi t + \dfrac{2\pi}{3}\right)$ (SI)，求此振动的周期、振幅、初相、速度最大值和加速度最大值。

**解：**

- 振幅 $A = 0.1\,\text{m}$
- 角频率 $\omega = 8\pi$，$T = \dfrac{2\pi}{\omega} = \dfrac{2\pi}{8\pi} = 0.25\,\text{s}$
- 初相 $\varphi_0 = \dfrac{2\pi}{3}$
- 速度最大值 $v_{\max} = A\omega = 0.1 \times 8\pi = 2.5\,\text{m/s}$
- 加速度最大值 $a_{\max} = A\omega^2 = 0.1 \times (8\pi)^2 = 63.1\,\text{m/s}^2$

**题2.** 质点做简谐运动，振动方程 $x = A\cos(\omega t + \varphi)$，当 $t = T/2$（$T$ 为周期）时，质点的速度为（  ）

$A.\ -A\omega\sin\varphi \quad B.\ A\omega\sin\varphi \quad C.\ -A\omega\cos\varphi \quad D.\ A\omega\cos\varphi \quad E.\ 0$

**答：B**

**解：**

$$v = \frac{dx}{dt} = -A\omega\sin(\omega t + \varphi)\Big|_{t=T/2}$$

$$= -A\omega\sin\left(\omega\cdot\frac{T}{2} + \varphi\right) = -A\omega\sin\left(\omega\cdot\frac{2\pi/\omega}{2} + \varphi\right)$$

$$= -A\omega\sin(\pi + \varphi) = A\omega\sin\varphi$$

**题3.** 将倔强系数为 $k$ 的轻质弹簧截去一半，然后一端固定，另一端下挂质量为 $m$ 的小球，组成振动系统。那么该系统的频率是（  ）

$A.\ \dfrac{1}{4\pi}\sqrt{\dfrac{k}{m}} \quad B.\ \dfrac{1}{2\pi}\sqrt{\dfrac{k}{m}} \quad C.\ \dfrac{1}{2\sqrt{2}\pi}\sqrt{\dfrac{k}{m}} \quad D.\ \dfrac{\sqrt{2}}{2\pi}\sqrt{\dfrac{k}{m}}$

**答：D**

**解：** 两段半弹簧并联：$\dfrac{1}{k'} + \dfrac{1}{k'} = \dfrac{1}{k} \Rightarrow k' = 2k$

$$\omega = \sqrt{\frac{k'}{m}} = \sqrt{\frac{2k}{m}}, \quad \nu = \frac{\omega}{2\pi} = \frac{\sqrt{2}}{2\pi}\sqrt{\frac{k}{m}}$$

### 1. 振动的能量

简谐运动的**机械能守恒**：

- 机械能 = 动能 + 势能
- $E = \dfrac{1}{2}mv^2 + \dfrac{1}{2}kx^2$
- 在最大位移处（$x=\pm A$，$v=0$）：动能 $E_k = 0$，势能 $E_p = \dfrac{1}{2}kA^2$
- 总机械能：$E = \dfrac{1}{2}kA^2$（**不变**）

<img src="assets/2-1-振动的能量.svg" alt="振动的能量" style="width:30vw;display:block;margin:0 auto;"/>

**题1.** 质点做简谐运动，从平衡位置运动到最大位移处时，质点的动能 ______，势能 ______，总的机械能 ______。（填增大、减小或不变）

**答：** 减小，增大，不变

**解：** 从平衡位置（$x=0$，$v$ 最大）到最大位移处（$x=\pm A$，$v=0$），动能 $E_k = \frac{1}{2}mv^2$ 减小，势能 $E_p = \frac{1}{2}kx^2$ 增大；总机械能 $E = \frac{1}{2}kA^2$ 守恒不变。

**题2.** 一弹簧振子作简谐运动，当其偏离平衡位置的位移的大小为振幅的 $\dfrac{1}{4}$ 时，其动能为振动总能量的（　）。

$A.\ \dfrac{9}{16}\quad B.\ \dfrac{11}{16}\quad C.\ \dfrac{13}{16}\quad D.\ \dfrac{15}{16}$

**答：D**

**解：**

- 势能 $E_p = \dfrac{1}{2}k\left(\dfrac{A}{4}\right)^2 = \dfrac{1}{32}kA^2$
- 总机械能 $E = \dfrac{1}{2}kA^2$
- 动能 $E_k = E - E_p = \dfrac{1}{2}kA^2 - \dfrac{1}{32}kA^2 = \dfrac{15}{32}kA^2$
- $\dfrac{E_k}{E} = \dfrac{\dfrac{15}{32}kA^2}{\dfrac{1}{2}kA^2} = \dfrac{15}{16}$

**题3.** 有一水平的弹簧振子，弹簧的劲度系数 $k = 25\,\text{N/m}$，物体质量 $m = 1.0\,\text{kg}$，物体静止在平衡位置。设以水平向左的恒力 $F = 10\,\text{N}$ 作用在物体上（不计一切摩擦），使其由平衡位置向左运动了 $0.05\,\text{m}$，此时撤除力 $F$，当物体运动到最左边时开始计时，求物体的运动方程。

**解：**

- 由机械能守恒 $F\cdot x = \dfrac{1}{2}kA^2$，即 $10\times0.05 = \dfrac{1}{2}\times25\times A^2 \Rightarrow A = 0.2\,\text{m}$
- 角频率 $\omega = \sqrt{\dfrac{k}{m}} = \sqrt{\dfrac{25}{1}} = 5\,\text{rad/s}$
- 由旋转矢量法知 $\varphi_0 = \pi$（物体从最左边 $x=-A$ 处开始计时）
- 运动方程：$x = 0.2\cos(5t + \pi)$

### 2. 振动的合成

**同方向同频率**的两个简谐运动 $x_1 = A_1\cos(\omega t + \varphi_1)$、$x_2 = A_2\cos(\omega t + \varphi_2)$ 合成：

$$A = \sqrt{A_1^2 + A_2^2 + 2A_1A_2\cos(\varphi_2 - \varphi_1)}$$

$$\tan\varphi = \frac{A_1\sin\varphi_1 + A_2\sin\varphi_2}{A_1\cos\varphi_1 + A_2\cos\varphi_2}$$

<img src="assets/2-2-振动的合成.svg" alt="振动的合成" style="width:30vw;display:block;margin:0 auto;"/>

**题1.** 某质点同时参与轴上的两个简谐运动：$x_1 = 0.03\cos\left(2\pi t + \dfrac{\pi}{3}\right)$，$x_2 = 0.05\cos\left(2\pi t - \dfrac{2\pi}{3}\right)$（SI），合成振动的振动方程为 ______。

**解：**

**解法一（旋转矢量法）：** 相位差 $\varphi_2 - \varphi_1 = -\dfrac{2\pi}{3} - \dfrac{\pi}{3} = -\pi$，两振动方向相反，故

$$A = 0.05 - 0.03 = 0.02\,\text{m},\qquad \varphi_0 = -\frac{2\pi}{3}$$

$$\Rightarrow x = 0.02\cos\left(2\pi t - \frac{2\pi}{3}\right)$$

**解法二（公式法）：**

$$A = \sqrt{A_1^2 + A_2^2 + 2A_1A_2\cos(\varphi_2-\varphi_1)} = \sqrt{0.03^2 + 0.05^2 + 2\times0.03\times0.05\cos(-\pi)} = 0.02$$

$$\tan\varphi = \frac{0.03\sin\frac{\pi}{3} + 0.05\sin\left(-\frac{2\pi}{3}\right)}{0.03\cos\frac{\pi}{3} + 0.05\cos\left(-\frac{2\pi}{3}\right)} = \sqrt{3}$$

由旋转矢量法可知 $\varphi = -\dfrac{2\pi}{3}$，故 $x = 0.02\cos\left(2\pi t - \dfrac{2\pi}{3}\right)$。

### 1. 认识机械波

**机械波的形成：** 波源振动带动相邻质点依次振动，振动形式在介质中由近及远传播。介质中各质点只在自己的平衡位置附近振动，**不随波迁移**，传播的是振动形式和能量。

<figure>
<img src="assets/3-1-横波形成与传播.svg" alt="横波的形成与传播：绳上质点上下振动、波形向右传播" style="width:30vw;display:block;margin:0 auto;"/>
<figcaption style="text-align:center;font-size:0.9em;color:#666;">绳上各质点上下振动，波形沿 +x 方向传播；右为质点振动图 x-t</figcaption>
</figure>

**波速、波长、周期的关系：**

$$u = \frac{\lambda}{T} = \lambda \nu$$

- 波速 $u$：波形传播的速度，由**介质**决定
- 波长 $\lambda$：一个完整波形沿传播方向占据的长度，等于波线上相位差为 $2\pi$ 的两点间距离
- 周期 $T$：波传播一个波长所需的时间，等于波源的振动周期（由**波源**决定）

**两点间相位差：**

$$\Delta\varphi = \frac{2\pi}{\lambda}\,\Delta x \quad\Longleftrightarrow\quad \frac{\lambda}{\Delta x} = \frac{2\pi}{\Delta\varphi}$$

> [!tip] 记忆口诀
> "见者有份"：波长对应 $2\pi$ 相位，两点距离 $\Delta x$ 占波长多少份，相位差就占 $2\pi$ 多少份。

#### 波动方程（沿 +x 方向传播）

原点 $O$ 的振动方程：$y = A\cos(\omega t + \varphi_0)$

若波沿 $+x$ 方向传播，$x$ 处质点的振动比 $O$ 点**落后** $\Delta t = \dfrac{x}{u}$，故

$$y = A\cos\left[\omega\left(t - \frac{x}{u}\right) + \varphi_0\right] = A\cos\left[2\pi\left(\nu t - \frac{x}{\lambda}\right) + \varphi_0\right] = A\cos\left[\omega t + \varphi_0 - \frac{2\pi}{\lambda}x\right]$$

若波沿 $-x$ 方向传播，$x$ 处质点的振动比 $O$ 点**超前**，则

$$y = A\cos\left[\omega\left(t + \frac{x}{u}\right) + \varphi_0\right] = A\cos\left[2\pi\left(\nu t + \frac{x}{\lambda}\right) + \varphi_0\right] = A\cos\left[\omega t + \varphi_0 + \frac{2\pi}{\lambda}x\right]$$

<figure>
<img src="assets/3-2-波动方程推导.svg" alt="波动方程推导：波形图与波速方向" style="width:30vw;display:block;margin:0 auto;"/>
<figcaption style="text-align:center;font-size:0.9em;color:#666;">t=0 时刻的波形图，波沿 +x 传播，$x$ 处质点相位落后于原点</figcaption>

> [!warning] 易错点
> 判断传播方向时，"上坡下、下坡上"：在波形图上升段（沿波传播方向）质点向下振动，下降段质点向上振动。

#### 例题

**题1.** 已知一平面简谐波的波动方程为：$y = 2.0\cos\left[2\pi\left(t - \dfrac{x}{8}\right) + \dfrac{\pi}{3}\right](\text{m})$，则此波沿 $x$ 轴 ______ 方向传播，波速为 ______，波长为 ______，原点处初相为 ______。

**答：** 正；$8\,\text{m/s}$；$8\,\text{m}$；$\dfrac{\pi}{3}$

**解：** 波动方程与标准式 $y = A\cos\left[2\pi\left(\nu t - \dfrac{x}{\lambda}\right) + \varphi_0\right]$ 对照：

- 括号内为 $\left(t - \dfrac{x}{8}\right)$，$x$ 前为负号 ⟹ 沿 $+x$（正）方向传播
- 波长 $\lambda = 8\,\text{m}$，频率 $\nu = 1\,\text{Hz}$
- 波速 $u = \lambda\nu = 8\times1 = 8\,\text{m/s}$
- 初相 $\varphi_0 = \dfrac{\pi}{3}$

<hr>

**题2.** 一横波沿绳子传播时，波的表达式为 $y = 0.05\cos(10\pi t - 4\pi x)$（SI），则（　）。

$A.\ 波长为\ 0.5\,\text{m} \quad B.\ 波速为\ 5\,\text{m/s} \quad C.\ 波速为\ 25\,\text{m/s} \quad D.\ 频率为\ 2\,\text{Hz}$

**答：A**

**解：** 对照标准式 $y = A\cos\left[\omega t + \varphi_0 - \dfrac{2\pi}{\lambda}x\right]$：

- 由 $-4\pi x = -\dfrac{2\pi}{\lambda}x \Rightarrow \lambda = 0.5\,\text{m}$ ✓
- $\omega = 10\pi \Rightarrow T = \dfrac{2\pi}{\omega} = 0.2\,\text{s}$
- $u = \dfrac{\lambda}{T} = \dfrac{0.5}{0.2} = 2.5\,\text{m/s}$（B、C 均错）
- $\nu = \dfrac{1}{T} = \dfrac{1}{0.2} = 5\,\text{Hz}$（D 错）

<hr>

**题3.** 频率为 $100\,\text{Hz}$，传播速度为 $300\,\text{m/s}$ 的平面简谐波，波线上距离小于波长的两点振动的相位差为 $\dfrac{\pi}{3}$，则两点相距（　）。

$A.\ 2.86\,\text{m} \quad B.\ 2.19\,\text{m} \quad C.\ 0.5\,\text{m} \quad D.\ 0.25\,\text{m}$

**答：C**

**解：**

$$\lambda = uT = u\cdot\frac{1}{\nu} = 300 \times \frac{1}{100} = 3\,\text{m}$$

$$\Delta\varphi = \frac{2\pi}{\lambda}\Delta x \Rightarrow \frac{\pi}{3} = \frac{2\pi}{3}\Delta x \Rightarrow \Delta x = 0.5\,\text{m}$$

### 2. 波动方程

> [!note] 解题三步法
> ① 求原点振动方程 $y = A\cos(\omega t + \varphi_0)$（旋转矢量法定 $\varphi_0$）
> ② 求波速 $u = \dfrac{\lambda}{T} = \lambda\nu$
> ③ 代入波动方程 $y = A\cos\left[\omega\left(t \mp \dfrac{x}{u}\right) + \varphi_0\right]$

#### 例题

（1）$O$ 点的振动方程；

（2）该波的波动方程；

（3）$x = 60\,\text{m}$ 处质点的振动方程和速度表达式。

</figure>

**解：**

（1）振幅 $A = 0.1\,\text{m}$，$\omega = \dfrac{2\pi}{T} = \dfrac{2\pi}{2} = \pi\ \text{rad/s}$

由旋转矢量法得 $\varphi_0 = -\dfrac{2\pi}{3}$（$t=0$ 时原点位移为负、且向 $-y$ 方向运动），故

$$y = 0.1\cos\left(\pi t - \frac{2\pi}{3}\right)$$

（2）$\lambda = 40\,\text{m}$，$u = \dfrac{\lambda}{T} = \dfrac{40}{2} = 20\,\text{m/s}$，波沿 $+x$ 传播：

$$y = 0.1\cos\left[\pi\left(t - \frac{x}{20}\right) - \frac{2\pi}{3}\right]$$

（3）将 $x = 60\,\text{m}$ 代入：

$$y = 0.1\cos\left[\pi\left(t - \frac{60}{20}\right) - \frac{2\pi}{3}\right] = 0.1\cos\left(\pi t - \frac{11\pi}{3}\right)$$

速度表达式：

$$v = \frac{dy}{dt} = -0.1\pi\sin\left(\pi t - \frac{11\pi}{3}\right)$$

**题2.** 一平面简谐波在介质中以波速 $u = 2\,\text{m/s}$ 沿 $x$ 轴负方向传播，原点 $O$ 处质点的振动曲线如图所示，求：

（1）原点 $O$ 的质点的振动方程；

（2）该波的波动方程；

（3）$x = 20\,\text{m}$ 处质点的振动方程。

<figure>
<img src="assets/3-4-波形图-沿x负向.svg" alt="原点振动曲线 T=8s，A=4cm，波沿 -x 传播" style="width:30vw;display:block;margin:0 auto;"/>
<figcaption style="text-align:center;font-size:0.9em;color:#666;">原点振动曲线：A=4cm，T=8s；波沿 -x 方向传播，u=2m/s</figcaption>
</figure>

**解：**

（1）振幅 $A = 4\times10^{-2}\,\text{m}$，周期 $T = 8\,\text{s}$，$\omega = \dfrac{2\pi}{T} = \dfrac{2\pi}{8} = \dfrac{\pi}{4}\ \text{rad/s}$

由旋转矢量法得 $\varphi_0 = -\dfrac{\pi}{2}$，故

$$y = 4\times10^{-2}\cos\left(\frac{\pi}{4}t - \frac{\pi}{2}\right)$$

（2）波沿 $-x$ 方向传播，$u = 2\,\text{m/s}$：

$$y = 4\times10^{-2}\cos\left[\frac{\pi}{4}\left(t + \frac{x}{2}\right) - \frac{\pi}{2}\right]$$

$$y = 4\times10^{-2}\cos\left[\frac{\pi}{4}\left(t + \frac{20}{2}\right) - \frac{\pi}{2}\right] = 4\times10^{-2}\cos\left(\frac{\pi}{4}t + 2\pi\right) = 4\times10^{-2}\cos\left(\frac{\pi}{4}t\right)$$

**题3.** 一平面简谐波沿 $Ox$ 轴的负方向传播，波长为 $\lambda$，$P$ 处质点的振动规律如图所示，已知 $P$ 点与 $O$ 点的距离为 $d$。

（1）求 $P$ 处质点的振动方程；

（2）求此波的波动表达式。

**解：**

（1）由振动图：振幅 $A$，$\varphi_0 = \pi$，$t = 1\,\text{s}$ 时 $y = 0$，即

$$0 = A\cos(\omega + \pi) \Rightarrow \omega + \pi = \frac{3\pi}{2} \Rightarrow \omega = \frac{\pi}{2}$$

$$y_P = A\cos\left(\frac{\pi}{2}t + \pi\right)$$

（2）$T = \dfrac{2\pi}{\omega} = \dfrac{2\pi}{\pi/2} = 4\,\text{s}$，$u = \dfrac{\lambda}{T} = \dfrac{\lambda}{4}$

以 $P$ 为原点（波沿 $-x$ 传播，$O$ 在 $P$ 的左侧 $d$ 处）：

$$y = A\cos\left[\frac{\pi}{2}\left(t + \frac{x}{\lambda/4}\right) + \pi\right] = A\cos\left[\frac{\pi}{2}\left(t + \frac{4x}{\lambda}\right) + \pi\right]$$

以 $O$ 为原点（$O$ 点比 $P$ 点振动超前 $\dfrac{d}{u}$）：

$$y = A\cos\left[\frac{\pi}{2}\left(t + \frac{4(x-d)}{\lambda}\right) + \pi\right]$$

> [!tip] 波沿 $-x$ 传播的波动方程
> 以振动规律已知的点 $P$ 为原点，$x$ 取正方向为 $-x$ 方向；以 $O$ 为原点时，$O$ 点比 $P$ 点超前 $d/u$，故相位项为 $+\dfrac{2\pi d}{\lambda}$（对应 $t + \dfrac{x+d'}{u}$ 形式）。
