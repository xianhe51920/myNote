# 物理笔记整理规范

本规范用于本目录内大学物理网课笔记的续写、校对和配图，由参与整理的 AI 共同遵循。后续新增要求可直接写入文末“用户追加要求”，也可修改对应条款。

## 1. 要求的适用顺序

1. 用户在当前任务中的明确要求优先。
2. 本文“用户追加要求”中针对同一事项的最新明确要求优先于旧条款；具体要求优先于一般要求。
3. 其余事项按本文和 [SVG 画图规范](assets/画图规范.md) 执行。本文调整了某项画图约定时，按本文的新约定执行。
4. 既有笔记用于延续格式，不能把其中的笔误或错误推导当作规范。

追加要求没有提及的部分，继续沿用现有规范。常规整理、校对和配图按已授权范围执行，不必为每一道题或每一张图重复确认。

## 2. 文件与目录

| 位置 | 用途 |
| --- | --- |
| `大二上物理.md` | 正式课程笔记，按课时顺序续写 |
| `截图/课时…/` | 对应课时的原始课程截图等素材 |
| `assets/` | 正文引用的 SVG 图示 |
| `assets/画图规范.md` | SVG 绘制细则 |
| `物理笔记整理规范.md` | 本文，统一整理要求与用户追加要求 |

- 当前沿用单篇课程笔记，不自行拆分成多个重复版本；用户要求调整结构时再统一修改目录与链接。
- 脚本、OCR 结果、下载缓存、测试输出、进度记录和临时预览保存在各 AI 自己的工作区。
- 保留已有原始素材；修改共享文件前重新读取当前内容，注意其他 AI 可能正在编辑。
- 不因整理笔记自动执行 Git 提交、推送或修改仓库忽略规则；按用户另行要求处理。

## 3. 内容依据与课程范围

- 以用户指定的课程合集、分集视频及配套课件为主要依据，本地截图用于对照。先核对分集目录和本地课时的对应关系，再判断哪些内容已完成。
- 保留老师讲授的主要知识点、解题方法、代表例题和必要的图示信息；口头重复、无关闲聊和操作停顿可省略。
- 字幕和 OCR 只能辅助整理。公式、正负号、上下标、数值、单位和图中方向必须结合画面或其他可靠材料核对。
- 仅看到截图、字幕或课件时，准确说明实际可核对的材料范围；不能据此声称已完整观看所有视频。
- 缺失材料时，先完成可确定的内容，记录具体缺口。不得编造题干、选项、数据、课程进度或未看到的推导。
- 可以补充理解所需的中间推导和基础说明。自行增加的例题注明“补充例题”，不要当作课程原题。
- “必考”、重要程度、占分等信息，只在课程或用户提供依据时保留；它们是对应课程的备考提示，不作为所有学校考试的统一结论。

## 4. 课时结构与正文写法

标题层级沿用现有形式：

```text
# 大二上物理
## 课时四 双缝干涉
### 1. 知识点名称
#### 例题
```

每个课时按实际内容组织以下部分，不机械堆叠空标题：

1. **考点表**：考点、重要程度、占分、常见题型；没有可靠依据的列可省略。
2. **知识点**：物理含义、适用条件、符号与单位、核心公式、必要推导。
3. **图示**：紧邻首次需要该图的文字或例题。
4. **例题与解析**：完整题意、答案和可复现的推导步骤。
5. **方法与易错点**：总结方向、相位、单位、适用条件等容易混淆之处。

- 用中文说明物理过程，避免只罗列公式。表格用于比较或汇总，连续推导用正文和公式表达。
- 不在学习正文中堆放 AI 工作日志、工具说明、整理时间或处理过程；确实影响理解的来源差异、条件限制应在对应知识点说明。
- 同一知识点重复出现时可引用前文，保留新增条件和方法，避免复制大段相同内容。
- 保持现有 Markdown、LaTeX 与提示块的阅读习惯；标题不跳级，表格和列表前后留空行。

## 5. 公式、符号与物理正确性

- 行内公式用 `$…$`，独立公式用 `$$…$$`；不要用图片替代可编辑的公式。
- 首次出现的量说明含义；题目与解答统一单位，必要时先换算为 SI 单位。数值结果的精度与题目数据相称。
- 公式要写清适用条件。例如机械能守恒需说明系统和外力做功情况；波速由介质决定等结论应放在相应模型条件下理解。
- 选定坐标原点、正方向和计时起点后，题干、图、公式、解释必须一致。改变约定时明确说明，不能在解答中悄悄切换。
- 简谐运动统一核对 $x=A\cos(\omega t+\varphi_0)$、$v=-A\omega\sin(\omega t+\varphi_0)$ 和 $a=-\omega^2x$；用初始位移与初速度共同判断初相，不能只看余弦值。
- 行波明确区分质点振动方向与波传播方向。以 $\omega t$ 为正时间项时，沿 $+x$ 传播用 $\omega t-kx$，沿 $-x$ 传播用 $\omega t+kx$，其中 $k=2\pi/\lambda$。
- 区分相位差的带符号定义和相位差大小；涉及不同参考点时先写出点的位置，再转换相位。
- 光学题明确光程差、相位差、半波损失和干涉/衍射条件；热学题明确系统、过程与功的正负号约定。
- 课件或现有笔记有明显错误时，应核实并改正，必要时用一句话说明订正原因。不能为了贴合原文保留错误结论。

## 6. 例题整理

- 题号在每个知识小节内依次编号，沿用 `**题1.**`、`**答：**`、`**解：**` 等格式。
- 题干应保留已知条件、所求量和必要选项。依赖图形的题目必须提供对应图，不留下无图可看的“如图所示”。
- 选择题保留足以理解和辨认答案的选项，不能只有无法核对的选项字母。选项图需要重绘或提供明确的文字描述。
- 解答写出所用规律、代入关系和结果；关键符号判断、相位象限、坐标变换等不能用一句“由图可知”跳过。
- 多种解法确有学习价值时并列保留，注明各自思路；单纯重复代数步骤可合并。
- 数值题检查量纲和初始条件，必要时把最终表达式代回原条件。图像题检查截距、斜率、极值、周期和传播方向。

## 7. SVG 图示

详细操作遵循 [SVG 画图规范](assets/画图规范.md)，并统一以下要求：

- 物理模型、旋转矢量、振动/波形曲线、光路、热力学过程等适合示意的内容优先重绘为 SVG；原始截图保留为素材，不以整张截图代替整理后的正文。
- 文件名用“课时-题号或序号-含义.svg”，放在 `assets/`，正文使用相对路径。已有文件名和引用不为统一命名而随意更换。
- 默认嵌入格式：

```html
<img src="assets/4-1-双缝干涉.svg" alt="图中物理对象和关键信息的说明" style="width:30vw;display:block;margin:0 auto;"/>
```

- 配色采用用户选定的 **C「钢蓝图纸」**：整幅背景 `#E8EFF5`，绘图区 `#F3F7FA`，主线 `#346E9D`，辅助线 `#6B9CBE`，坐标轴 `#526D83`，正文文字 `#243E56`。完整色表见 [SVG 画图规范](assets/画图规范.md)。使用 `sans-serif` 字体，物体填充也沿用蓝色系。
- **禁止透明背景**：SVG 内必须有覆盖整个 `viewBox` 的不透明背景矩形，底色固定为 `#E8EFF5`。不能仅给网页或 Markdown 容器设置背景，也不能只绘制局部面板而让外围透明。底色不随阅读软件的浅色/暗色主题改变。
- 曲线按公式计算，坐标、刻度、振幅、周期、相位和题目数据一致。示意图不按比例时，应避免给出误导性的几何关系，必要时注明“示意”。
- 标出必要的坐标正方向、单位、波传播方向、速度/力方向或光路方向；图的含义必须与正文一致。
- 画布四周留足边距，避免裁切、重叠和标注压线；弹簧、墙、木块等连接点准确衔接。
- 完成后检查 SVG 的 XML 合法性、正文路径和实际显示效果，并在浅色、暗色页面上确认整图底色完整、文字和线条可辨。数学上正确但标注无法辨认的图仍需调整。

## 8. 完成前核查

- **覆盖范围**：对照本次指定的课时，确认知识点、例题、题图没有遗漏；建了目录不等于完成内容。
- **物理内容**：核对公式、条件、符号、单位、数值，以及题干—图示—答案之间的一致性。
- **阅读显示**：检查公式解析、表格、提示块、标题层级、图片加载和链接；查看配图有无裁切或重叠。
- **工作衔接**：说明本次实际完成的范围和仍缺的材料，不能把尚未核对或无法获取的部分报告为已完成。
- 校验脚本和过程记录保存在整理者自己的工作区，正式笔记保留学习内容。

```text
### 要求标题
- 要求内容：
- 适用范围：全课程 / 指定课时 / 指定题目或图示
- 对已有内容的处理：同步修改 / 仅对后续新增内容生效
```

### SVG 采用 C「钢蓝图纸」，禁止透明背景

- 要求内容：使用已选定的 C 版蓝色调与不透明灰蓝底色，具体色值和实现要求见第 7 节及 SVG 画图规范。
- 适用范围：本课程后续新增或重绘的 SVG 配图。
- 对已有内容的处理：已有图在修改或重绘时按此规范迁移。
