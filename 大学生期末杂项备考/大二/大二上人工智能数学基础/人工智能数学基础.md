## 复习时先辨认问题

| 问题 | 优先考虑 |
| --- | --- |
| 一个连续结果怎样随若干解释变量变化？ | 线性回归 |
| 结果为是否发生、计数或不同处理组的均值？ | 广义线性模型或方差分析 |
| 已有类别标签，要给新样本分类？ | 判别分析 |
| 没有类别标签，要按相似性分组？ | 聚类分析 |
| 一组变量过多，希望保留主要变异？ | 主成分分析 |
| 希望用少数潜在因素解释变量间相关？ | 因子分析 |
| 希望同时观察列联表的行类别与列类别关联？ | 对应分析 |
| 希望研究两组变量整体的线性关联？ | 典型相关分析 |
| 只有对象间距离，希望恢复低维位置？ | 多维标度分析 |
| 希望按若干指标作综合评分？ | 综合评价 |

## 使用约定

- 默认数据矩阵为 $n\times p$：行是样本，列是变量；随机向量写成列向量。公式中的转置用 $^{\mathsf T}$。
- $S$ 默认使用分母 $n-1$ 的样本协方差阵；采用 $n$ 为分母时明确标为 $S_n$。
- 完整保留课件的主要知识结构和代表例题，重复演示页合并；课件中明显笔误在对应知识点说明。
- 课件提到的 `mvstats5.xlsx`、`msaR.r` 等配套文件未见于当前目录。涉及这些文件的例题保留分析方法与已展示结果，不补造缺失数据。可独立复算的例子给出完整数据或明确标为演练例。
- R 示例优先使用基础函数和 `MASS`；课件自定义函数会说明依赖，并给出基础函数的对应做法。
