# 第 11 章 典型相关分析

| 复习要点 | 掌握目标 |
| --- | --- |
| 目标 | 研究两组变量整体的线性关联 |
| 典型变量 | 两组各取线性组合，使配对相关最大 |
| 特征根 | 区分相关系数 $\rho$ 与特征值 $\rho^2$ |
| 检验与解释 | 联合检验、载荷、交叉载荷和冗余度 |
| 诊断 | 样本量、共线性、过拟合与验证 |

## 1. 简单、复、典型相关的关系

| 方法 | 变量结构 |
| --- | --- |
| 简单相关 | 一个变量与另一个变量 |
| 复相关 | 一个变量与一组变量 |
| 典型相关 CCA | 一组变量与另一组变量 |

课件例有能源消费与经济增长两组指标，以及生理指标（体重、腰围、脉搏）与运动指标（引体向上、仰卧起坐、跳跃）的两组数据。

CCA 通常把两组对称处理，不必指定谁是因谁是果。它不是把两组分别做 PCA 后只取各自第一主成分；PCA 最大化组内方差，CCA 最大化跨组相关。

## 2. 总体典型相关的数学模型

中心化列向量 $X\in\mathbb R^p,Y\in\mathbb R^q$，协方差分块为

$$\Sigma=\begin{pmatrix}\Sigma_{XX}&\Sigma_{XY}\\\Sigma_{YX}&\Sigma_{YY}\end{pmatrix}.$$

寻找 $U=a^{\mathsf T}X,V=b^{\mathsf T}Y$，最大化

$$\operatorname{Corr}(U,V)=\frac{a^{\mathsf T}\Sigma_{XY}b}{\sqrt{a^{\mathsf T}\Sigma_{XX}a}\sqrt{b^{\mathsf T}\Sigma_{YY}b}}.$$

由于比例缩放不改变相关，可加约束

$$a^{\mathsf T}\Sigma_{XX}a=1,\qquad b^{\mathsf T}\Sigma_{YY}b=1.$$

于是第一对典型变量方差为 1，相关为最大值 $\rho_1$。

## 3. 特征值与白化推导

一阶条件给出

$$\Sigma_{XY}b=\rho\Sigma_{XX}a,\qquad\Sigma_{YX}a=\rho\Sigma_{YY}b.$$

若组内协方差阵可逆，消去 $b$ 得

$$\Sigma_{XX}^{-1}\Sigma_{XY}\Sigma_{YY}^{-1}\Sigma_{YX}a=\rho^2a.$$

**特征值是 $\rho^2$，典型相关是其非负平方根。** 不同课件有时以 $\lambda$ 表示相关、有时表示平方，应先看定义。

数值上可对白化矩阵做 SVD：

$$K=\Sigma_{XX}^{-1/2}\Sigma_{XY}\Sigma_{YY}^{-1/2}=L\operatorname{diag}(\rho_j)R^{\mathsf T}.$$

系数 $a_j=\Sigma_{XX}^{-1/2}l_j$、$b_j=\Sigma_{YY}^{-1/2}r_j$。组内阵奇异时不能机械求逆，需要减少冗余变量或采用明确的正则化方法。

## 4. 后续典型变量与性质

第二对在与之前已选典型变量不相关的条件下最大化剩余跨组相关，最多得到 $m\le\min(p,q)$ 对：

$$1\ge\rho_1\ge\rho_2\ge\cdots\ge\rho_m\ge0.$$

采用单位方差约束时：

$$\operatorname{Cov}(U_i,U_j)=\operatorname{Cov}(V_i,V_j)=0\ (i\ne j),$$

$$\operatorname{Cov}(U_i,V_j)=0\ (i\ne j),\qquad\operatorname{Corr}(U_i,V_i)=\rho_i.$$

“不同典型变量互不相关”不能一般性改为“相互独立”；联合正态下才有进一步的独立结论。

相关系数不受变量单位改变的影响，但原始系数的数值会随单位变。符号可成对同时反向，解释时应结合载荷而非只记正负号。

## 5. 样本估计与显著性检验

用样本协方差分块代替总体协方差，得样本典型相关 $r_j$。样本量太小或组内高度共线时，样本相关可虚高；满秩和有效样本量都要检查。

顺序检验从第 $s$ 对起剩余总体典型相关是否全为 0：

$$H_0:\rho_s=\cdots=\rho_m=0,\qquad\Lambda_s=\prod_{j=s}^{m}(1-r_j^2).$$

常见 Bartlett 卡方近似为

$$\chi_s^2=-\left[n-1-\frac{p+q+1}{2}\right]\log\Lambda_s,$$

自由度 $(p-s+1)(q-s+1)$，需要独立样本、联合正态等相应条件与足够样本量。这是近似检验；软件还可能使用 Rao 的 F 近似，输出不能不加说明地混为同一种统计量。

检验显著性、典型相关大小、原变量的方差解释比例应联合判断；不是相关很高就一定代表两组绝大部分信息都被解释。

## 6. 三种解释量与冗余度

### 6.1 典型权重

$a_j,b_j$ 是线性组合系数。受单位、组内共线性影响较大，不能只按绝对系数大小断言哪个变量“最重要”。

### 6.2 典型载荷与交叉载荷

- 典型载荷：$\operatorname{Corr}(X_i,U_j)$、$\operatorname{Corr}(Y_i,V_j)$。
- 交叉载荷：$\operatorname{Corr}(X_i,V_j)$、$\operatorname{Corr}(Y_i,U_j)$。

载荷表示原始变量与本组典型变量的关系；交叉载荷联系到另一组。应分清矩阵行列，不能将载荷当成权重直接相乘求典型得分。

### 6.3 方差提取与冗余度

第 $j$ 对中，$V_j$ 对原 $Y$ 组的平均方差提取比例为

$$VE_{Y,j}=\frac1q\sum_{i=1}^{q}\operatorname{Corr}(Y_i,V_j)^2.$$

由 $X$ 组通过这对关系解释 $Y$ 组的冗余度为

$$RD_{Y\leftarrow X,j}=VE_{Y,j}\,r_j^2.$$

另一个方向用 $VE_{X,j}$，所以两个方向通常不同。$r_j^2$ 是两条典型变量之间共享的方差比例，不是两组全部变量的解释比例。

课件举例使用 $0.4508\times0.633\approx0.2854$。这里 0.633 是该对典型相关的平方，不能称作另一组原始变量的方差提取率。结论只是对应方向约解释 28.54% 的标准化方差。

## 7. R 演练

以下用鸢尾花的萼片、花瓣两组变量演练，不作为课件能源数据的替代结果。

```r
X <- as.matrix(iris[,1:2])
Y <- as.matrix(iris[,3:4])
cc <- cancor(X,Y)
cc$cor
Xc <- sweep(X,2,cc$xcenter,"-")
Yc <- sweep(Y,2,cc$ycenter,"-")
U0 <- Xc %*% cc$xcoef
V0 <- Yc %*% cc$ycoef
# 显式归一化到样本方差1，统一本文的数学约定
U <- scale(U0,center=FALSE,scale=apply(U0,2,sd))
V <- scale(V0,center=FALSE,scale=apply(V0,2,sd))
cor(U,V)
LX <- cor(X,U)
LY <- cor(Y,V)
cross.X <- cor(X,V)
cross.Y <- cor(Y,U)
VE.Y <- colMeans(LY^2)
RD.Y <- VE.Y * cc$cor^2
```

`cancor()` 返回系数的数值归一化不必正好等于本文采用的单位样本方差；显式标准化不改变典型相关。计算新样本得分时须沿用训练中心与同一套系数。[R 的 cancor 文档](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/cancor.html)

## 8. 课件案例与报告流程

能源消费与经济增长案例报告前两对典型相关约 0.9990、0.9549。数据含时间趋势等共同结构时，高相关并不自动意味着稳定预测能力，更不能直接解释为因果。

报告顺序：确定两组变量及理论意义 → 检查缺失、共线性和样本量 → 估计典型对 → 顺序检验 → 解释载荷与冗余度 → 留出或重抽样验证稳定性。

补充课件演示 SAS `PROC CANCORR`，`VAR` 和 `WITH` 分别指定两组变量；输出中的 canonical correlation、标准化权重、structure、redundancy 应按上述定义阅读。R、SAS 输出可不同名，但应回到同一数学量比较。
