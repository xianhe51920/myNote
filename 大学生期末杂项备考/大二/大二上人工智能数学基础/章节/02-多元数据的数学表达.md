## 1. 数据的收集与编码

课件以股民投资调查说明多元资料的整理：每位被调查者是一行，年龄、性别、职业、教育程度、投资结果等是一列。

- 定量变量：如年龄、金额，可按其数值意义计算。
- 定性变量：如性别、职业，数字编码首先代表类别，不能因为编码为 1、2、3 就任意求平均。
- 有序变量：如教育程度、满意等级，有顺序但相邻级差未必相等。
- 缺失值要单独标记，不能把“缺失”编码成一个正常取值后直接参与统计。

课件把年龄分组后编码，这是离散化，会丢失组内差异；原始年龄与年龄组编码是两种不同数据。

## 2. 数据矩阵与随机向量

设有 $n$ 个样本、$p$ 个变量：

$$X=(x_{ij})_{n\times p}=\begin{pmatrix}x_{11}&\cdots&x_{1p}\\\vdots&&\vdots\\x_{n1}&\cdots&x_{np}\end{pmatrix}.$$

第 $i$ 行是样本向量的转置 $\boldsymbol x_i^{\mathsf T}$，第 $j$ 列是第 $j$ 个变量的 $n$ 次观测。

总体随机向量 $\boldsymbol\xi=(\xi_1,\ldots,\xi_p)^{\mathsf T}$ 的均值向量和协方差阵为

$$\boldsymbol\mu=E(\boldsymbol\xi),\quad\Sigma=E[(\boldsymbol\xi-\boldsymbol\mu)(\boldsymbol\xi-\boldsymbol\mu)^{\mathsf T}].$$

这里 $\boldsymbol\mu$ 为 $p\times1$，$\Sigma$ 为 $p\times p$。统计量的计算不要求数据一定正态；某些检验和分布结论才额外要求正态性。

## 3. 样本均值、离差阵、协方差阵

### 3.1 均值向量

$$\bar{\boldsymbol x}=\frac1n\sum_i\boldsymbol x_i=\frac1nX^{\mathsf T}\boldsymbol1_n.$$

### 3.2 中心化与离差平方和乘积阵

令

$$H=I_n-\frac1n\boldsymbol1_n\boldsymbol1_n^{\mathsf T},\quad X_c=HX=X-\boldsymbol1_n\bar{\boldsymbol x}^{\mathsf T}.$$

$H^{\mathsf T}=H$、$H^2=H$、$H\boldsymbol1_n=0$。样本离差平方和乘积阵为

$$A=X_c^{\mathsf T}X_c=X^{\mathsf T}HX=\sum_i(\boldsymbol x_i-\bar{\boldsymbol x})(\boldsymbol x_i-\bar{\boldsymbol x})^{\mathsf T}.$$

其对角项是各变量离均差平方和，非对角项是两变量离均差乘积和。

### 3.3 协方差阵

$$S=\frac{A}{n-1},\qquad s_{jk}=\frac1{n-1}\sum_i(x_{ij}-\bar x_j)(x_{ik}-\bar x_k).$$

若使用分母 $n$，则另记 $S_n=A/n$。它们的比例为 $S_n=(n-1)S/n$。

**维数订正：** 基础概率课件最后一页把 $X$ 写为 $n\times p$ 后，又出现 $XHX^{\mathsf T}$ 的形式。这与该维数约定不匹配。本笔记统一采用行样本约定，所以是 **$X^{\mathsf T}HX$**；若以列表示样本，数据矩阵必须相应转置。

### 3.4 协方差阵的性质

- $S$ 对称且半正定：$a^{\mathsf T}Sa\ge0$。
- 对角线为各变量的样本方差，不能据某个负的非对角元素就判定矩阵不是半正定。
- $\operatorname{rank}(S)\le\min(p,n-1)$；$p\ge n$ 时不能指望其可逆。
- 方差为 0 的常数列不能直接做相关标准化。

## 4. 标准化与相关系数矩阵

令 $D=\operatorname{diag}(s_1,\ldots,s_p)$，其中 $s_j=\sqrt{s_{jj}}>0$：

$$Z=X_cD^{-1},\qquad R=D^{-1}SD^{-1}=\frac1{n-1}Z^{\mathsf T}Z.$$

$Z$ 每列的均值为 0、样本方差为 1；$R$ 对角线为 1，且 $|r_{jk}|\le1$。

**注意：** 若按通常的样本标准差标准化，相关阵中仍有 $1/(n-1)$。课件某些页面简写为 $R=Z^{\mathsf T}Z$，只有将每列再归一化为长度 1 时才可这样写。

相关系数无单位；协方差的单位是两个变量单位的乘积。改变测量单位会改变协方差阵，一般不会改变相关阵。

## 5. 线性变换的数字特征

对随机向量 $\eta=B\xi+c$，

$$E(\eta)=B\mu+c,\qquad\operatorname{Cov}(\eta)=B\Sigma B^{\mathsf T}.$$

平移不改变协方差；数乘 $a$ 使方差乘以 $a^2$。这个公式用于回归预测、PCA 投影与因子模型。

## 6. 手算演练：三行两列的数据

以下小数据用于演练课件的矩阵公式：

$$X=\begin{pmatrix}1&2\\2&4\\3&3\end{pmatrix},\quad\bar{\boldsymbol x}=(2,3)^{\mathsf T},\quad X_c=\begin{pmatrix}-1&-1\\0&1\\1&0\end{pmatrix}.$$

$$A=\begin{pmatrix}2&1\\1&2\end{pmatrix},\quad S=\begin{pmatrix}1&1/2\\1/2&1\end{pmatrix},\quad R=S.$$

这里恰好两个样本标准差都为 1，所以 $R=S$；不是所有数据都如此。

## 7. R 中的向量、矩阵与数据框

### 7.1 创建和合并

```r
x1 <- c(171,175,159,155,152,158,154,164,168,166,159,164)
x2 <- c(57,64,41,38,35,44,41,51,57,49,47,46)
X <- cbind(height=x1, weight=x2)  # 按列合并，12×2
rbind(x1, x2)                    # 按行合并，2×12
A <- matrix(1:12, nrow=3, ncol=4) # 默认按列填入
B <- matrix(1:12, nrow=3, byrow=TRUE)
d <- data.frame(height=x1, weight=x2)
dim(X); nrow(X); ncol(X)
```

**课件订正：** `rbind()` 是按行合并，`cbind()` 是按列合并；不能跟随课件中错写的注释反着记。

矩阵各元素通常为同一基本类型；数据框不同列可以为不同类型。类别变量显式用 `factor()`，不要依赖不同 R 版本下字符列是否自动变为因子的默认行为。

### 7.2 运算

```r
t(A)
A + B
A * B                    # 逐元素乘法
A %*% t(B)               # 矩阵乘法
diag(3)                  # 3×3 单位阵
diag(diag(3))            # 提取单位阵对角线，得到长度3的向量
C <- matrix(c(3,-1,-1,3), 2, 2)
solve(C)                 # 可逆时求逆
solve(C, c(1,2))         # 直接解 Cb = (1,2)，不必先显式求逆
eigen(C, symmetric=TRUE)
chol(C)                  # 实对称正定时：t(U) %*% U = C
svd(A)
```

`diag()` 随输入不同有提取或构造作用；要把矩阵的对角元素重新构成对角阵，应使用 `diag(diag(C))`。

### 7.3 行列统计量

```r
rowSums(X); rowMeans(X)
colSums(X); colMeans(X)
apply(X, 1, mean)         # 第1维是行
apply(X, 2, var)          # 第2维是列
cov(X)
cor(X)
Z <- scale(X, center=TRUE, scale=TRUE)
crossprod(Z) / (nrow(Z)-1)
```

课件中的 `aplly` 应为 `apply`；均值用 `rowMeans/colMeans`，不是 `colSums`。

## 8. 定性数据的频数表

```r
survey <- data.frame(
  sex=factor(c("男","女","女","男","女")),
  result=factor(c("赚","平","亏","赚","赚"))
)
table(survey$sex)
table(survey$sex, survey$result)
prop.table(table(survey$sex, survey$result), margin=1)
ftable(survey)
```

频数与比例要区分；按行归一化、按列归一化回答的条件概率不同。
