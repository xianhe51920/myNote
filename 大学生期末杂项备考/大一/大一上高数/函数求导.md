## 常用函数求导公式

### 基本初等函数导数
- $(C)' = 0$ （$C$为常数）
- $(x^\mu)' = \mu x^{\mu-1}$
- $(a^x)' = a^x \ln a$ （$a>0, a\neq 1$)
- $(e^x)' = e^x$
- $(\log_a x)' = \frac{1}{x \ln a}$ （$a>0, a\neq 1$)
- $(\ln x)' = \frac{1}{x}$
- $(\sin x)' = \cos x$
- $(\cos x)' = -\sin x$
- $(\tan x)' = \sec^2 x$
- $(\cot x)' = -\csc^2 x$
- $(\sec x)' = \sec x \tan x$
- $(\csc x)' = -\csc x \cot x$
- $(\arcsin x)' = \frac{1}{\sqrt{1-x^2}}$
- $(\arccos x)' = -\frac{1}{\sqrt{1-x^2}}$
- $(\arctan x)' = \frac{1}{1+x^2}$
- $(\text{arccot } x)' = -\frac{1}{1+x^2}$

### 求导法则
- **加减法则**：$(u \pm v)' = u' \pm v'$
- **乘法法则**：$(uv)' = u'v + uv'$
- **除法法则**：$\left(\frac{u}{v}\right)' = \frac{u'v - uv'}{v^2}$ ($v \neq 0$)
- **复合函数求导（链式法则）**：$[f(g(x))]' = f'(g(x)) \cdot g'(x)$ 或 $\frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx}$
