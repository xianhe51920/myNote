## 微分方程的基本概念与一阶微分方程

### 基本概念
- **微分方程**：含有未知函数及其导数的方程
- **阶**：方程中出现的最高阶导数的阶数
- **解**：代入方程使其成为恒等式的函数
- **通解**：含有与方程阶数相同个数的独立任意常数的解
- **特解**：确定了通解中任意常数后的解
- **初始条件**：确定特解的条件

### 一阶微分方程的基本类型

#### 1. 可分离变量方程
形式：$\frac{dy}{dx} = f(x)g(y)$ 或 $M_1(x)M_2(y)dx + N_1(x)N_2(y)dy = 0$
解法：分离变量 $\frac{dy}{g(y)} = f(x)dx$，然后积分

#### 2. 齐次方程
形式：$\frac{dy}{dx} = f\left(\frac{y}{x}\right)$
解法：令 $u = \frac{y}{x}$，则 $y = ux$，$\frac{dy}{dx} = u + x\frac{du}{dx}$
代入得：$u + x\frac{du}{dx} = f(u)$，然后分离变量

#### 3. 一阶线性微分方程
形式：$\frac{dy}{dx} + P(x)y = Q(x)$
通解公式：$y = e^{-\int P(x)dx} \left[ \int Q(x)e^{\int P(x)dx}dx + C \right]$

#### 4. 伯努利方程
形式：$\frac{dy}{dx} + P(x)y = Q(x)y^n \quad (n \neq 0,1)$
解法：令 $z = y^{1-n}$，化为关于 $z$ 的一阶线性方程


## 可降阶的高阶微分方程

### 类型一：$y^{(n)} = f(x)$
解法：连续积分 $n$ 次
$y^{(n-1)} = \int f(x)dx + C_1$
$y^{(n-2)} = \int \left[ \int f(x)dx + C_1 \right] dx + C_2$
...
$y = \int \cdots \int f(x) dx \cdots dx + C_1x^{n-1} + \cdots + C_{n-1}x + C_n$

### 类型二：$y'' = f(x, y')$（不显含 $y$）
解法：令 $p = y'$，则 $y'' = \frac{dp}{dx}$
原方程化为：$\frac{dp}{dx} = f(x, p)$，为一阶方程

### 类型三：$y'' = f(y, y')$（不显含 $x$）
解法：令 $p = y'$，则 $y'' = \frac{dp}{dx} = \frac{dp}{dy} \cdot \frac{dy}{dx} = p\frac{dp}{dy}$
原方程化为：$p\frac{dp}{dy} = f(y, p)$，为一阶方程


## 高阶线性微分方程

### 基本理论
1. **二阶线性微分方程一般形式**：
   $y'' + P(x)y' + Q(x)y = f(x)$
   - 齐次方程：$f(x) = 0$
   - 非齐次方程：$f(x) \neq 0$

2. **解的叠加原理**（齐次方程）：
   若 $y_1(x)$ 和 $y_2(x)$ 是齐次方程的解，则
   $C_1y_1(x) + C_2y_2(x)$ 也是解

3. **线性无关**：
   若 $\frac{y_1(x)}{y_2(x)} \neq$ 常数，则 $y_1$ 和 $y_2$ 线性无关

4. **通解结构**：
   - 齐次方程：$y = C_1y_1(x) + C_2y_2(x)$（$y_1, y_2$ 线性无关）
   - 非齐次方程：$y = Y(x) + y^*(x)$
     其中 $Y(x)$ 为对应齐次方程的通解，$y^*(x)$ 为非齐次方程的特解

5. **常数变易法**（求非齐次特解）：
   已知齐次方程通解 $Y = C_1y_1 + C_2y_2$
   令 $y^* = v_1(x)y_1 + v_2(x)y_2$
   解方程组：
   $\begin{cases}
   v_1'y_1 + v_2'y_2 = 0 \\
   v_1'y_1' + v_2'y_2' = f(x)
   \end{cases}$
   得 $v_1', v_2'$，积分得 $v_1, v_2$

### 常系数线性微分方程

#### 二阶常系数齐次线性方程
形式：$y'' + py' + qy = 0$（$p, q$ 为常数）
特征方程：$r^2 + pr + q = 0$
通解情况：
1. 两个不等实根 $r_1, r_2$：$y = C_1e^{r_1x} + C_2e^{r_2x}$
2. 两个相等实根 $r_1 = r_2$：$y = (C_1 + C_2x)e^{r_1x}$
3. 共轭复根 $r = \alpha \pm i\beta$：$y = e^{\alpha x}(C_1\cos\beta x + C_2\sin\beta x)$

#### 常系数非齐次线性方程
形式：$y'' + py' + qy = f(x)$
通解：$y = Y(x) + y^*(x)$

**特解 $y^*$ 的求法（待定系数法）**：
根据 $f(x)$ 的形式设特解

1. $f(x) = P_m(x)e^{\lambda x}$（$P_m(x)$ 为 $m$ 次多项式）
   - 若 $\lambda$ 不是特征根：设 $y^* = Q_m(x)e^{\lambda x}$
   - 若 $\lambda$ 是特征方程的单根：设 $y^* = xQ_m(x)e^{\lambda x}$
   - 若 $\lambda$ 是特征方程的重根：设 $y^* = x^2Q_m(x)e^{\lambda x}$

2. $f(x) = e^{\alpha x}[P_l(x)\cos\beta x + P_n(x)\sin\beta x]$
   设 $y^* = x^ke^{\alpha x}[Q_m(x)\cos\beta x + R_m(x)\sin\beta x]$
   其中 $m = \max(l, n)$，$k$ 按 $\alpha + i\beta$ 是特征方程的根的重数取：
   - 不是特征根：$k=0$
   - 是单根：$k=1$
   - 是重根：$k=2$
