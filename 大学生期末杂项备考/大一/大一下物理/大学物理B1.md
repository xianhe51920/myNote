## 1. 位移/速度/加速度

### 基本概念和公式

① **位矢（位置矢量）**：
$$\vec{r} = x\vec{i} + y\vec{j}$$

② **位移**：
$$\Delta\vec{r} = \vec{r}_B - \vec{r}_A$$

③ **路程**：$\overset{\frown}{AB}$（弧长）

④ **速度**：
- 平均速度：$\vec{\bar{v}} = \frac{\Delta\vec{r}}{\Delta t} = \frac{\vec{r}_B - \vec{r}_A}{t_2 - t_1}$
- 瞬时速度：$\vec{v} = \frac{d\vec{r}}{dt} = \frac{dx}{dt}\vec{i} + \frac{dy}{dt}\vec{j}$
- 大小：$|\vec{v}| = \left|\frac{d\vec{r}}{dt}\right| = \sqrt{\left(\frac{dx}{dt}\right)^2 + \left(\frac{dy}{dt}\right)^2} = \frac{ds}{dt}$

⑤ **加速度**：
$$\vec{a} = \frac{d\vec{v}}{dt} = \frac{dv_x}{dt}\vec{i} + \frac{dv_y}{dt}\vec{j} = \frac{dv}{dt}\vec{\tau} + \frac{v^2}{R}\vec{n}$$
- 切向加速度：$a_t = \frac{dv}{dt}$
- 法向加速度：$a_n = \frac{v^2}{R}$
- 大小：$|\vec{a}| = \sqrt{\left(\frac{dv_x}{dt}\right)^2 + \left(\frac{dv_y}{dt}\right)^2} = \sqrt{\left(\frac{dv}{dt}\right)^2 + \left(\frac{v^2}{R}\right)^2}$

![圆周运动的速度和加速度图示](1.1质点运动学(一)/2.png)

### 例题

**题1**：一质点在xoy平面内运动，其运动学方程为$x = 3\cos4t$，$y = 3\sin4t$，则$t$时刻质点的位矢$\vec{r}(t) =$ ______

**解**：$\vec{r} = x\vec{i} + y\vec{j} = 3\cos4t\ \vec{i} + 3\sin4t\ \vec{j}$

---

**题2**：已知平面内运动方程为$x = at^2$，$y = bt^2$（其中$a, b$为常量），则该质点运动轨迹为（ ）

A. 双曲线 B. 抛物线 C. 圆周 D. 直线

**解**：
$$\begin{cases} x = at^2 \\ y = bt^2 \end{cases} \Rightarrow \frac{x}{y} = \frac{a}{b} \Rightarrow y = \frac{b}{a}x$$
轨迹为直线，选**D**

---

**题3**：一运动质点在某瞬间矢径$\vec{r}(x, y)$的端点处，其速度大小为（ ）

A. $\frac{dr}{dt}$ B. $\frac{d\vec{r}}{dt}$ C. $\frac{d|\vec{r}|}{dt}$ D. $\sqrt{\left(\frac{dx}{dt}\right)^2 + \left(\frac{dy}{dt}\right)^2}$

**解**：速度大小为$|\vec{v}| = \sqrt{\left(\frac{dx}{dt}\right)^2 + \left(\frac{dy}{dt}\right)^2}$，选**D**

![位矢和位移图示](1.1质点运动学(一)/4.png)

---

**题4**：质点作半径为$R$的变速圆周运动时的加速度大小为（ ）（$v$表示任一时刻质点的速率）

A. $\frac{dv}{dt}$ B. $\frac{v^2}{R}$ C. $\frac{dv}{dt} + \frac{v^2}{R}$ D. $\sqrt{\left(\frac{dv}{dt}\right)^2 + \left(\frac{v^2}{R}\right)^2}$

**解**：加速度大小为$|\vec{a}| = \sqrt{\left(\frac{dv}{dt}\right)^2 + \left(\frac{v^2}{R}\right)^2}$，选**D**

![变速圆周运动加速度图示](1.1质点运动学(一)/5.png)

## 2. $\vec{r} \to \vec{v} \to \vec{a}$ 型

已知位矢求速度和加速度，解题方法：**求导**

### 例题

**题1**：质点的运动方程为$\vec{r} = (2 + 2t^2)\vec{i} + \left(\frac{1}{3}t^3 + 2t\right)\vec{j}$，求$t = 2$时的速度和加速度。

**解**：
$$\vec{v} = \frac{d\vec{r}}{dt} = 4t\vec{i} + (t^2 + 2)\vec{j}$$
$$\vec{v}\big|_{t=2} = 8\vec{i} + 6\vec{j}$$

$$\vec{a} = \frac{d\vec{v}}{dt} = 4\vec{i} + 2t\vec{j}$$
$$\vec{a}\big|_{t=2} = 4\vec{i} + 4\vec{j}$$

---

**题2**：已知某质点的运动方程为$x = 2t$，$y = 2 - t^2$，式中$x$以$m$计，$t$以$s$计，求：
1) 位置矢量表达式，速度和加速度表达式；
2) 前2s内质点的平均速度和平均加速度；
3) 第2s内质点的平均速度；
4) 计算1s末和2s末质点的加速度。

**解**：

(1) 
$$\vec{r} = 2t\vec{i} + (2 - t^2)\vec{j}$$
$$\vec{v} = \frac{d\vec{r}}{dt} = 2\vec{i} - 2t\vec{j}$$
$$\vec{a} = \frac{d\vec{v}}{dt} = -2\vec{j}$$

(2) 前2s内（$t=0$到$t=2$）：
$$\vec{r}_0 = 2\vec{j}, \quad \vec{v}_0 = 2\vec{i}$$
$$\vec{r}_2 = 4\vec{i} - 2\vec{j}, \quad \vec{v}_2 = 2\vec{i} - 4\vec{j}$$
$$\Delta\vec{r} = \vec{r}_2 - \vec{r}_0 = 4\vec{i} - 4\vec{j}$$
$$\vec{\bar{v}} = \frac{\Delta\vec{r}}{\Delta t} = \frac{4\vec{i} - 4\vec{j}}{2 - 0} = 2\vec{i} - 2\vec{j}$$
$$\Delta\vec{v} = \vec{v}_2 - \vec{v}_0 = -4\vec{j}$$
$$\vec{\bar{a}} = \frac{\Delta\vec{v}}{\Delta t} = \frac{-4\vec{j}}{2 - 0} = -2\vec{j}$$

(3) 第2s内（$t=1$到$t=2$）：
$$\vec{r}_1 = 2\vec{i} + \vec{j}, \quad \vec{r}_2 = 4\vec{i} - 2\vec{j}$$
$$\Delta\vec{r} = \vec{r}_2 - \vec{r}_1 = 2\vec{i} - 3\vec{j}$$
$$\vec{\bar{v}} = \frac{\Delta\vec{r}}{\Delta t} = 2\vec{i} - 3\vec{j}$$

(4) 1s末和2s末质点的加速度：
$$\vec{a} = -2\vec{j}$$

## 3. $\vec{a} \to \vec{v} \to \vec{r}$ 型

已知加速度求速度和位矢，解题方法：**积分**

### 解题方法

$$a = \frac{dv}{dt} \Rightarrow dv = adt \Rightarrow \int_{v_0}^{v} dv = \int_{0}^{t} adt$$

$$v = \frac{dx}{dt} \Rightarrow dx = vdt \Rightarrow \int_{x_0}^{x} dx = \int_{0}^{t} vdt$$

### 匀变速直线运动公式

$$v = v_0 + at$$
$$x = x_0 + v_0t + \frac{1}{2}at^2$$
$$v_2^2 - v_1^2 = 2a(x_2 - x_1)$$

### 例题

**题1**：设质点沿$x$轴作匀变速直线运动，加速度为$a$不随时间变化，初速度为$v_0$，初位置为$x_0$，试根据速度、加速度的定义求出该质点的速度公式和运动学方程。

**解**：
$$a = \frac{dv}{dt} \Rightarrow dv = adt \Rightarrow \int_{v_0}^{v} dv = \int_{0}^{t} adt$$
$$v - v_0 = at \Rightarrow v = v_0 + at$$

$$v = \frac{dx}{dt} \Rightarrow dx = vdt = (v_0 + at)dt \Rightarrow \int_{x_0}^{x} dx = \int_{0}^{t} (v_0 + at)dt$$
$$x - x_0 = v_0t + \frac{1}{2}at^2 \Rightarrow x = x_0 + v_0t + \frac{1}{2}at^2$$

---

**题2**：一质点做直线运动，加速度$a = 2m/s^2$，开始时$v_1 = 2m/s$，一段时间后$v_2 = 6m/s$，问质点在这段时间内的位移大小。

**解**：由$v_2^2 - v_1^2 = 2a(x_2 - x_1)$
$$6^2 - 2^2 = 2 \times 2 \times (x_2 - x_1)$$
$$36 - 4 = 4(x_2 - x_1)$$
$$x_2 - x_1 = 8\ m$$

---

**题3**：质点沿直线运动，加速度$a = 4 - t^2$，式中$a$的单位为$m/s^2$，$t$的单位为$s$，如果当$t = 3s$时，$x = 9m$，$v = 2m/s$，求质点的运动方程。

**解**：
$$a = 4 - t^2 = \frac{dv}{dt} \Rightarrow dv = (4 - t^2)dt \Rightarrow \int_{v_0}^{v} dv = \int_{0}^{t} (4 - t^2)dt$$
$$v = v_0 + 4t - \frac{1}{3}t^3 \quad \text{①}$$

$$v = \frac{dx}{dt} \Rightarrow dx = vdt = \left(v_0 + 4t - \frac{1}{3}t^3\right)dt \Rightarrow \int_{x_0}^{x} dx = \int_{0}^{t} \left(v_0 + 4t - \frac{1}{3}t^3\right)dt$$
$$x = x_0 + v_0t + 2t^2 - \frac{1}{12}t^4 \quad \text{②}$$

将$t = 3s$，$x = 9m$，$v = 2m/s$代入①②得：
$$v_0 = -1m/s, \quad x_0 = 0.75m$$

所以质点的运动方程为：
$$x = 0.75 - t + 2t^2 - \frac{1}{12}t^4 \quad (m)$$

---

**题4**：一质点沿一直线运动，其加速度为$a = -2x$，式中$x$的单位为$m$，$a$的单位为$m/s^2$。试求该质点的速度$v$与位置坐标$x$之间的关系。设当$x_0 = 1$时，$v_0 = 4m/s$。

**解**：
$$a = -2x = \frac{dv}{dt} = \frac{dv}{dx} \cdot \frac{dx}{dt} = \frac{dv}{dx} \cdot v$$
$$\frac{dv}{dx} \cdot v = -2x$$

分离变量得：
$$vdv = -2xdx \Rightarrow \int_{v_0}^{v} vdv = \int_{x_0}^{x} -2xdx$$

$$\frac{1}{2}v^2 - \frac{1}{2}v_0^2 = -x^2 + x_0^2$$

代入$x_0 = 1$，$v_0 = 4$：
$$\frac{1}{2}v^2 - 8 = -x^2 + 1$$
$$v^2 = -2x^2 + 18$$

## 4. 相对运动

### 相对关系

$$\vec{v}_{绝对} = \vec{v}_{牵连} + \vec{v}_{相对}$$
$$\vec{a}_{绝对} = \vec{a}_{牵连} + \vec{a}_{相对}$$

### 例题

**题1**：甲船以$v_1 = 10m/s$的速度向南航行，乙船以$v_2 = 10m/s$的速度向东航行，则甲船上的人观察乙船的速度大小为 ______

**解**：
- $v_1$：牵连速度（甲船相对于地面）
- $v_2$：绝对速度（乙船相对于地面）

$$\vec{v}_2 = \vec{v}_1 + \vec{v}_{相对}$$
$$\vec{v}_{相对} = \vec{v}_2 - \vec{v}_1$$

由勾股定理：
$$v_{相对} = \sqrt{v_1^2 + v_2^2} = \sqrt{10^2 + 10^2} = 10\sqrt{2}\ m/s$$

## 1. 角位移/角速度/角加速度

### 基本概念和公式

- **角位移**：$\theta$，单位：$\text{rad}$（弧度）
- **角速度**：$\omega = \frac{d\theta}{dt}$，单位：$\text{rad/s}$
- **角加速度**：$\beta = \frac{d\omega}{dt} = \frac{d^2\theta}{dt^2}$，单位：$\text{rad/s}^2$
- **周期**：$T = \frac{2\pi}{\omega}$，单位：$\text{s}$（秒）

![角位移/角速度/角加速度图示](1.2质点运动学(二)/2.png)

---

## 2. $\theta \to \omega \to \beta$ 型

已知角位置求角速度和角加速度，解题方法：**求导**

### 例题

**题1**：某质点上的角位置和时间关系为$\theta = 4t - 3t^2 + t^3$（SI），则在2秒末的角速度大小$\omega =$ ______，角加速度大小$\beta =$ ______，在2秒末到4秒末这段时间内，平均角速度大小$\bar{\omega} =$ ______。

**解**：
$$\omega = \frac{d\theta}{dt} = 4 - 6t + 3t^2$$
$$\omega\big|_{t=2} = 4 - 6 \times 2 + 3 \times 2^2 = 4\ \text{rad/s}$$

$$\beta = \frac{d\omega}{dt} = -6 + 6t$$
$$\beta\big|_{t=2} = -6 + 6 \times 2 = 6\ \text{rad/s}^2$$

$$t = 2\ \text{s}\ \text{时}\ \theta_2 = 4$$
$$t = 4\ \text{s}\ \text{时}\ \theta_4 = 32$$
$$\Delta\theta = 32 - 4 = 28$$

$$\bar{\omega} = \frac{\Delta\theta}{\Delta t} = \frac{28}{4 - 2} = 14\ \text{rad/s}$$

---

## 3. $\beta \to \omega \to \theta$ 型

已知角加速度求角速度和角位置，解题方法：**积分**

### 解题方法

$$\beta = \frac{d\omega}{dt} \Rightarrow d\omega = \beta dt \Rightarrow \int_{\omega_0}^{\omega} d\omega = \int_{0}^{t} \beta dt$$

$$\omega = \frac{d\theta}{dt} \Rightarrow d\theta = \omega dt \Rightarrow \int_{\theta_0}^{\theta} d\theta = \int_{0}^{t} \omega dt$$

### 匀变速圆周运动公式

$$\omega = \omega_0 + \beta t$$
$$\theta = \theta_0 + \omega_0t + \frac{1}{2}\beta t^2$$
$$\omega_2^2 - \omega_1^2 = 2\beta(\theta_2 - \theta_1)$$

### 例题

**题1**：已知匀变速圆周运动，角加速度为$\beta$，$t = 0$时，角速度为$\omega_0$，角位移为$\theta_0$，试用定义公式，求角速度和角位移表达式。

**解**：
$$\beta = \frac{d\omega}{dt} \Rightarrow d\omega = \beta dt \Rightarrow \int_{\omega_0}^{\omega} d\omega = \int_{0}^{t} \beta dt$$
$$\omega - \omega_0 = \beta t \Rightarrow \omega = \omega_0 + \beta t$$

$$\omega = \frac{d\theta}{dt} \Rightarrow d\theta = \omega dt = (\omega_0 + \beta t)dt \Rightarrow \int_{\theta_0}^{\theta} d\theta = \int_{0}^{t} (\omega_0 + \beta t)dt$$
$$\theta - \theta_0 = \omega_0t + \frac{1}{2}\beta t^2 \Rightarrow \theta = \theta_0 + \omega_0t + \frac{1}{2}\beta t^2$$

---

**题2**：搅拌机叶片以恒定角加速度$1.50\ \text{rad/s}^2$转动，求：
(1) 从静止启动后经过多少时间角速度将达到$36.0\ \text{rad/s}$？
(2) 在此时间内共转过多少转？

**解**：
(1) 由$\omega = \omega_0 + \beta t$得：
$$36 = 0 + 1.5t \Rightarrow t = 24\ \text{s}$$

(2) 由$\theta = \theta_0 + \omega_0t + \frac{1}{2}\beta t^2$：
$$\theta = 0 + 0 + \frac{1}{2} \times 1.5 \times 24^2 = 432\ \text{rad}$$

$$n = \frac{\theta}{2\pi} = \frac{432}{2 \times 3.14} = 68.8\ \text{（转）}$$

---

**题3**：绕定轴转动的飞轮，均匀减速，$t = 0$时$\omega_0 = 5\ \text{rad/s}$，$t = 20$时$\omega = 0.8\omega_0$，则飞轮的角加速度$\beta =$ ______ $\text{rad/s}^2$，转过的角度$\theta =$ ______ $\text{rad}$。

**解**：
$$t = 0\ \text{时}\ \omega_0 = 5,\quad t = 20\ \text{时}\ \omega = 0.8\omega_0 = 4$$

由$\omega = \omega_0 + \beta t$：
$$4 = 5 + \beta \times 20 \Rightarrow \beta = -0.05\ \text{rad/s}^2$$

由$\omega^2 - \omega_0^2 = 2 \cdot \beta \cdot \Delta\theta$：
$$\Delta\theta = \frac{\omega^2 - \omega_0^2}{2\beta} = \frac{4^2 - 5^2}{-2 \times 0.05} = 90\ \text{rad}$$

## 4. 角量与线量关系（必考）

### 基本关系

| 物理量 | 角量表达式 | 线量表达式 | 关系 |
|--------|------------|------------|------|
| 速度 | $\omega$ | $v$ | $v = \omega R$ |
| 切向加速度 | $\beta$ | $a_t$ | $a_t = \beta R$ |
| 法向加速度 | $\omega$ | $a_n$ | $a_n = \omega^2 R = \frac{v^2}{R}$ |

![角量与线量关系图示](1.2质点运动学(二)/7.png)

### 例题

**题1**：质点在作半径为$R$的圆周运动：
- 质点的线速度$v$与角速度$\omega$的关系为$v = \omega R$；
- 质点的切向加速度$a_t$与角加速度$\beta$的关系为$a_t = \beta R$；
- 质点的法向加速度$a_n$与角速度$\omega$的关系为$a_n = \omega^2 R$。

---

**题2**：质点沿半径为$R$的圆周运动，运动学方程为$\theta = 3 + 2t^2$（SI），则$t$时刻质点的法向加速度大小为$a_n =$ ______，切向加速度$a_t =$ ______。

**解**：
$$\omega = \frac{d\theta}{dt} = 4t,\quad \beta = \frac{d\omega}{dt} = 4$$

$$a_n = \omega^2 R = (4t)^2 R = 16Rt^2$$

$$a_t = \beta R = 4R$$

---

**题3**：一质点在半径为$0.1\ \text{m}$的圆周上运动，其角位置变化关系为$\theta = 2 + 4t^3$（rad）。问：
(1) 在$t = 2\ \text{s}$时，质点的法向加速度和切向加速度大小各为多少？
(2) 当切向加速度大小恰好等于总加速度大小的一半时，$\theta$值为多少？
(3) 在什么时刻，切向加速度和法向加速度恰好大小相等？

**解**：
$$\omega = \frac{d\theta}{dt} = 12t^2,\quad \beta = \frac{d\omega}{dt} = 24t$$

(1)
$$a_n = \omega^2 R = (12t^2)^2 \times 0.1 = 14.4t^4$$
$$a_n\big|_{t=2} = 14.4 \times 2^4 = 230.4\ \text{m/s}^2$$

$$a_t = \beta R = 24t \times 0.1 = 2.4t$$
$$a_t\big|_{t=2} = 2.4 \times 2 = 4.8\ \text{m/s}^2$$

(2)
$$a = \sqrt{a_t^2 + a_n^2} = \sqrt{(2.4t)^2 + (14.4t^4)^2}$$

依题意$a_t = \frac{1}{2}a$：
$$2.4t = \frac{1}{2}\sqrt{(2.4t)^2 + (14.4t^4)^2}$$
$$t^3 = \frac{\sqrt{3}}{6}$$
$$\theta = 2 + 4t^3 = 2 + 4 \times \frac{\sqrt{3}}{6} = 3.15\ \text{rad}$$

(3)
依题意$a_t = a_n$：
$$2.4t = 14.4t^4$$
解得：$t = 0.55\ \text{s}$

## 1. 常见力

### 基本概念和公式

1) **重力**：$G = mg$，$g = 9.8N/kg$

2) **弹力**：$F = kx$（$k$为弹性系数）

3) **摩擦力**：

   - ②静摩擦：$0 \leq f \leq \mu_s N$（$\mu_s$为最大静摩擦系数）

4) **万有引力**：$F = G\frac{Mm}{r^2}$，$G = 6.67 \times 10^{-11} N \cdot m^2/kg^2$

## 2. 牛顿三定律

### 牛顿三定律内容

1) **牛顿第一定律**：不受力或合外力为0，质点保持静止或匀速直线运动

2) **牛顿第二定律**：$F = ma$（力是物体产生加速度的原因）

3) **牛顿第三定律**：$F_{作用} = F_{反作用}$（作用力等于反作用力）

### 解题步骤

1) 选物体
2) 分析受力
3) 列方程
4) 求解

### 例题

**题1**：关于摩擦力的说法，下列哪一种说法正确（ ）

A. 摩擦力总是阻碍物体运动
B. 摩擦力的方向总是与物体运动方向相反
C. 摩擦力总是对物体做负功
D. 以上说法都不对

**解**：选**D**

**题2**：用水平力$F_N$把一个物体压着靠在粗糙的竖直墙面上保持静止，当$F_N$逐渐增大时，物体所受到的静摩擦力$F_f$的大小（ ）

A. 不为零，但保持不变
B. 随$F_N$成正比增大
C. 开始随$F_N$增大，达到某一最大值后就保持不变
D. 无法确定

**解**：$F_N = N$，$F_N$增大则$N$增大，但静摩擦力$F_f = mg$，与$F_N$无关，保持不变。选**A**

$$F - F_{AB} = m_1a \quad \text{②}$$

**题4**：设电梯中有一质量可以忽略的滑轮，在滑轮两侧用轻绳悬挂着质量分别为$m_1$和$m_2$的重物A和B，已知$m_1 > m_2$，当电梯匀速上升，求绳中的张力$T$和物体A相对于电梯的加速度$a$。

**题5**：一艘行驶的质量为$m$的快艇，在发动机关闭后，受到一阻力作用，且$f = -kv^2$，式中$k$为正常数，求快艇在关闭发动机后速度与行驶距离的关系。（已知发动机关闭时快艇速度为$v_0$）

**解**：根据牛顿第二定律：
$$f = -kv^2 = ma = m\frac{dv}{dt} = m\frac{dv}{dx} \cdot \frac{dx}{dt} = mv\frac{dv}{dx}$$
$$-kv = m\frac{dv}{dx}$$

分离变量：$\frac{1}{v}dv = -\frac{k}{m}dx$

两边同时积分：
$$\int_{v_0}^{v} \frac{1}{v}dv = \int_{0}^{x} -\frac{k}{m}dx$$
$$\ln v - \ln v_0 = -\frac{k}{m}x$$
$$\ln \frac{v}{v_0} = -\frac{k}{m}x$$
$$\frac{v}{v_0} = e^{-\frac{k}{m}x}$$
$$v = v_0 e^{-\frac{k}{m}x}$$

## 1. 动量定理

### 基本概念和公式

- **动量**：$\vec{p} = m\vec{v}$，单位：$kg \cdot m/s$
- **动量定理**：$\vec{I} = m\vec{v}_2 - m\vec{v}_1 = \int_{t_1}^{t_2} \vec{F}dt$，单位：$N \cdot s$

### 要点

①冲量为矢量，等于动量的矢量差，也等于冲力对时间的积分

②$\vec{F}$为冲力，为合外力

③$\vec{F}$若为常力，$\vec{I} = m\vec{v}_2 - m\vec{v}_1 = \vec{F} \cdot \Delta t$

### 例题

**题1**：一物体质量为$m$，$t_1$时刻速度大小为$v_0$，方向沿$x$负方向，$t_2$时刻速度大小仍为$v_0$，方向沿$y$轴正方向，$t_1$到$t_2$冲量大小为______

**解**：
$$I = \sqrt{(mv_0)^2 + (mv_0)^2} = \sqrt{2}mv_0$$

![动量定理矢量图示](1.4动量,冲量,动量守恒/3.png)

---

**题2**：一垒球的质量$m = 0.20kg$，如果其投出时的速度为$30m/s$，被棒击回的速度为$50m/s$，方向相反，球的冲量大小为______；球与棒的接触时间为$\Delta t = 0.0020s$，则棒击打垒球的平均冲力$F =$ ______

**解**：
$$I = mv_2 - mv_1 = 0.2 \times 50 - 0.2 \times (-30) = 16\ N \cdot s$$

$$I = F \cdot \Delta t$$
$$16 = F \times 0.002$$
$$F = 8000N$$

![垒球碰撞图示](1.4动量,冲量,动量守恒/4.png)

**题3**：质量为$3kg$的静止物体在水平力$F = 3t^2$（$N$）作用下，在光滑水平面上作直线运动，物体在$0 \sim 3$秒内获得的冲量______$N \cdot s$，第3秒末物体的速度值______$m/s$

**解**：
$$I = \int_{t_1}^{t_2} Fdt = \int_{0}^{3} 3t^2 dt = 27\ N \cdot s$$

$$I = mv_2 - mv_1 = mv_2$$
$$27 = 3 \times v_2 \Rightarrow v_2 = 9\ m/s$$

**题4**：一静止的质点，在合力为$\vec{F} = 10t\vec{i} + 2(2-t)\vec{j}$作用下，在$2s$末的动量为______

**解**：
$$F_x = 10t,\quad F_y = 2(2-t)$$

$$mv_{x_2} - 0 = \int_{0}^{2} F_x dt = \int_{0}^{2} 10t dt = 20$$

$$mv_{y_2} - 0 = \int_{0}^{2} F_y dt = \int_{0}^{2} 2(2-t) dt = 4$$

$$\vec{p}_2 = 20\vec{i} + 4\vec{j}$$

## 2. 动量守恒

### 动量守恒条件

1) $F_{合} = 0$：不受外力或所受合外力为零

2) 内力不改变系统的总动量（例如：爆炸）

3) 内力远大于外力时，也可认为$F_{合} = 0$

### 动量守恒定律

$$\sum m_i \vec{v}_{i1} = \sum m_i \vec{v}_{i2}$$

### 例题

**题1**：粒子B的质量是粒子A的质量的4倍，开始时粒子A的速度为$3\vec{i}$，粒子B的速度为$2\vec{i}$，由于两者的相互作用，粒子A的速度变为$7\vec{i}$，此时粒子B的速度为（ ）

A. $\vec{i}$ B. $2\vec{i}$ C. $0$ D. $5\vec{i}$

**解**：由动量守恒：
$$m \cdot 3 + 4m \cdot 2 = m \cdot 7 + 4m \cdot v_B$$
$$3 + 8 = 7 + 4v_B$$
$$v_B = 1$$

选**A**

**题2**：一人站在长度为$4m$的船一端，船漂浮于静止水面上。船的质量为$600kg$，人的质量为$80kg$，若此人从船头走到船尾，则船相对于水面移动了多少米？（忽略水对船的阻力）

**解**：水平方向动量守恒：
$$mv_{人} = Mv_{船} \Rightarrow m\frac{dx_1}{dt} = M\frac{dx_2}{dt}$$

整理得：$mdx_1 = Mdx_2$

两边同时积分：
$$\int_{0}^{x_1} mdx_1 = \int_{0}^{x_2} Mdx_2 \Rightarrow mx_1 = Mx_2$$

即：$80x_1 = 600x_2$

又：$x_1 + x_2 = 4$

联立两式解得：
$$\begin{cases} x_1 = 3.53m \\ x_2 = 0.47m \end{cases}$$

故船移动了$0.47m$

## 1. 做功

### 基本概念和公式

① **元功**：$dA = \vec{F} \cdot d\vec{r}$

② **功**：
$$A = \int \vec{F} \cdot d\vec{r}$$

当 $F = f(x)$ 时：
$$A = \int_{x_1}^{x_2} F dx$$

③ **恒力做功**：
$$A = \vec{F} \cdot \vec{r} = F_x x + F_y y + F_z z$$

![做功公式图示](1.5质点运动的功和能/2.png)

### 例题

**题1**：某质点在力 $F = (4 + 5x)$ 的作用下沿 $x$ 轴做直线运动，在从 $x = 0$ 移动到 $x = 1$ 的过程中，力 $F$ 所做的功为______

**解**：
$$A = \int_{0}^{1} F dx = \int_{0}^{1} (4 + 5x) dx = 4x + \frac{5}{2}x^2 \Big|_{0}^{1} = 4 + \frac{5}{2} = 6.5\ J$$

![做功例题1图示](1.5质点运动的功和能/3.png)

---

**题2**：一质点在恒力 $\vec{F} = 3\vec{i} - 5\vec{j} + 6\vec{k}$ 的作用下产生位移为 $\vec{r} = 2\vec{i} - 4\vec{j} - 3\vec{k}$，在该位移过程中所做的功为______

**解**：
$$A = \vec{F} \cdot \vec{r} = 3 \times 2 + (-5) \times (-4) + 6 \times (-3) = 6 + 20 - 18 = 8\ J$$


---

**题3**：一人从 $10m$ 深的井中提水，起始桶中装有 $10kg$ 的水，由于水桶漏水，每升高 $1m$ 要漏去 $0.2kg$ 的水，水桶被匀速地从井中提到井口，求人所做的功。

**解**：

设水桶升高 $x$ 米时，水的质量为：
$$m = 10 - 0.2x$$

人所施加的力为：
$$F = mg = (10 - 0.2x)g$$

人所做的功为：
$$A = \int_{0}^{10} F dx = \int_{0}^{10} (10 - 0.2x)g dx = g \left(10x - 0.1x^2\right) \Big|_{0}^{10} = g(100 - 10) = 90g = 882\ J$$

## 2. 动能定理

### 基本概念和公式

① **动能**：
$$E_k = \frac{1}{2}mv^2$$

② **动能定理**：
$$A = E_{k2} - E_{k1} = \frac{1}{2}mv_2^2 - \frac{1}{2}mv_1^2$$

合外力对物体所做的功等于物体动能的增量。


### 例题

**题1**：质量为 $1kg$ 的物体运动速率由 $2m/s$ 增加到 $4m/s$ 的过程中，合外力对它所做的功为______

**解**：
$$A = \frac{1}{2}mv_2^2 - \frac{1}{2}mv_1^2 = \frac{1}{2} \times 1 \times 4^2 - \frac{1}{2} \times 1 \times 2^2 = 8 - 2 = 6\ J$$

---

**题2**：用铁锤把钉子敲入墙面木板，设木板对钉子的阻力与钉子进入木板的深度成正比，即 $F = kx$。若第一次打击时，能把钉子打入木板 $1cm$。第二次打击时，保持第一次打击的速度，第二次能把钉子打入的深度为______

**解**：

设第一次打击前钉子速度为 $v$，第一次打击后钉子深度为 $x_1 = 1cm$

第一次打击：
$$\frac{1}{2}mv^2 = \int_{0}^{x_1} kx dx = \frac{1}{2}kx_1^2$$

第二次打击（钉子从深度 $x_1$ 打到深度 $x_2$）：
$$\frac{1}{2}mv^2 = \int_{x_1}^{x_2} kx dx = \frac{1}{2}k(x_2^2 - x_1^2)$$

由两次打击动能相等：
$$\frac{1}{2}kx_1^2 = \frac{1}{2}k(x_2^2 - x_1^2)$$
$$x_1^2 = x_2^2 - x_1^2$$
$$x_2^2 = 2x_1^2$$
$$x_2 = \sqrt{2}x_1 = \sqrt{2}cm$$

第二次打入深度：
$$\Delta x = x_2 - x_1 = (\sqrt{2} - 1)cm$$

![动能定理例题2图示](1.5质点运动的功和能/7.png)

---

**题3**：质量均匀分布的钢性链条，总长为 $L$，伸出光滑桌面的长度为 $a$，若由静止释放。求：链条全部脱离光滑桌面时速率。

**解**：

设链条线密度为 $\lambda = \frac{m}{L}$

链条从伸出 $a$ 到全部脱离桌面，重心下降高度：
$$h = \frac{L}{2} - \frac{a}{2} = \frac{L - a}{2}$$

链条重力做功：
$$A = mg \cdot h = m \cdot g \cdot \frac{L - a}{2}$$

由动能定理：
$$A = \frac{1}{2}mv^2 - 0$$
$$mg \cdot \frac{L - a}{2} = \frac{1}{2}mv^2$$
$$v = \sqrt{g(L - a)}$$

## 3. 保守力、势能

### 基本概念和公式

① **保守力**：做功与路径无关，只与始末位置有关的力。

② **保守力的特点**：
- 保守力做功与路径无关，只与始末位置有关
- 保守力沿一闭合路径运动一周，做功为零
- 势能的引入是以保守力做功为前提
- 不同的势能零点，对应的势能值不一样
- 势能大小 = 保守力把物体移至势能零点所做的功
- 保守力做正功，对应势能减小
- 功能计算时，功-能计算一个，就要忽略这个保守力

![保守力特点图示](1.5质点运动的功和能/10.png)

③ **常用保守力势能及零势能点**：

| 保守力 | 势能表达式 | 常用零势能点 |
|--------|------------|--------------|
| 重力 $G = mg$ | $E_p = mgh$ | 地面 |
| 弹力 $F = kx$ | $E_p = \frac{1}{2}kx^2$ | 平衡位置 |
| 万有引力 $F = G\frac{Mm}{r^2}$ | $E_p = -G\frac{Mm}{r}$ | 无穷远处 |
| 静电力 $F = \frac{1}{4\pi\varepsilon_0}\frac{q_1q_2}{r^2}$ | $E_p = \frac{1}{4\pi\varepsilon_0}\frac{q_1q_2}{r}$ | 无穷远处 |

## 4. 机械能守恒

### 基本概念和公式

① **机械能**：
$$E = E_k + E_p = \frac{1}{2}mv^2 + E_p$$

② **机械能守恒定律**：
$$E_{k1} + E_{p1} = E_{k2} + E_{p2}$$

1. 机械能只包含动能和势能
2. 系统内只有保守力做功，其他内力和一切外力都不做功


### 例题

**题1**：如图所示，质量 $m = 2kg$ 的物体从静止开始，沿 $1/4$ 圆弧从 $A$ 滑到 $B$，在 $B$ 处的速度大小为 $v = 6m/s$，已知圆的半径 $R = 4m$，则物体从 $A$ 到 $B$ 的过程中摩擦力对它所做的功为______

**解**：

$A$ 点机械能：
$$E_A = mgR$$

$B$ 点机械能：
$$E_B = \frac{1}{2}mv^2$$

摩擦力做功等于机械能损失：
$$A_f = E_B - E_A = \frac{1}{2}mv^2 - mgR = \frac{1}{2} \times 2 \times 6^2 - 2 \times 9.8 \times 4 = 36 - 78.4 = -42.4\ J$$

![机械能守恒例题1图示](1.5质点运动的功和能/14.png)

---

**题2**：质量为 $m$ 的子弹，穿过如图所示的摆锤后，速率由 $v$ 变为 $\frac{v}{2}$。已知摆锤的质量为 $M$，摆线的长度为 $L$，如果摆锤能在垂直平面内完成一个完全的圆周运动，子弹的速度最小值应为多大？

**解**：

子弹穿过摆锤瞬间，动量守恒：
$$mv = m \cdot \frac{v}{2} + Mv'$$
$$v' = \frac{m}{M} \cdot \frac{v}{2}$$

摆锤可以完成圆周运动，则在最高点满足：
$$Mg = M\frac{v_{最高}^2}{L}$$
$$v_{最高} = \sqrt{gL}$$

摆锤开始上扬，满足机械能守恒：
$$\frac{1}{2}Mv'^2 = \frac{1}{2}Mv_{最高}^2 + Mg \cdot 2L$$
$$\frac{1}{2}M \cdot \left(\frac{m}{M} \cdot \frac{v}{2}\right)^2 = \frac{1}{2}M \cdot gL + 2MgL$$
$$\frac{m^2v^2}{4M^2} = 5gL$$
$$v = \frac{2M}{m}\sqrt{5gL}$$

**题3**：子弹水平地射入一端固定在弹簧上的木块内，由弹簧压缩的距离求出子弹的速度。已知子弹质量是 $0.02kg$，木块质量是 $8.98kg$，弹簧的劲度系数是 $100N/m$，子弹射入木块后，弹簧被压缩 $0.1m$。设木块与平面间的动摩擦因数为 $0.2$，求子弹的速度。

**解**：

子弹射入木块瞬间，动量守恒：
$$mv = (m + M)v'$$
$$v' = \frac{m}{m + M}v = \frac{0.02}{0.02 + 8.98}v = \frac{0.02}{9}v$$

弹簧开始压缩，满足功能关系：
$$\frac{1}{2}(m + M)v'^2 - \mu(m + M)g \cdot x = \frac{1}{2}kx^2$$
$$\frac{1}{2} \times 9 \times \left(\frac{0.02}{9}v\right)^2 - 0.2 \times 9 \times 9.8 \times 0.1 = \frac{1}{2} \times 100 \times 0.1^2$$
$$\frac{1}{2} \times 9 \times \frac{0.0004}{81}v^2 - 1.764 = 0.5$$
$$\frac{0.0004}{18}v^2 = 2.264$$
$$v^2 = \frac{2.264 \times 18}{0.0004} = 101880$$
$$v = 319.2\ m/s$$

## 1. 求电场强度—离散型

### 基本概念和公式

**库仑定律**：
$$F = \frac{1}{4\pi\varepsilon_0} \cdot \frac{q \cdot q_0}{r^2}$$
(1) 同性相斥，异性相吸
(2) 电场力跟$q, q_0$电量成正比，跟$r^2$成反比
(3) 真空介电常量：$\varepsilon_0 = 8.85 \times 10^{-12}\ C^2/(N \cdot m^2)$

**电场强度**：
$$E = \frac{F}{q_0} = \frac{1}{4\pi\varepsilon_0} \cdot \frac{q}{r^2}$$
(矢量，有大小有方向)

(1) $\vec{E}$方向判定：将正电荷放入电场中，受力方向即$\vec{E}$的方向
(2) 电场强度跟场源电荷$q$和位置$r$有关，与试探电荷$q_0$无关

![离散型基本概念](2.1电场强度/2.png)

### 例题

**题1**：在点电荷$q_1$激发的电场中有一试探电荷$q_0$受力为$\vec{F}$，若将另一个点电荷$q_2$移入该区域后，$q_0$与$q_1$之间的作用力将（ ）

A. 不变 B. 变大 C. 变小 D. 无法确定

**解**：$q_0$与$q_1$之间的作用力只与它们之间的距离和电量有关，与$q_2$无关。选**A**

![题1图示](2.1电场强度/3.png)

---

**题2**：如图所示，求在$P$点和$Q$点处的场强和方向？

**解**：

**P点**：
$$E = E_1 - E_2 = \frac{1}{4\pi\varepsilon_0} \cdot \frac{q}{(2l)^2} - \frac{1}{4\pi\varepsilon_0} \cdot \frac{q}{(4l)^2} = \frac{3q}{64\pi\varepsilon_0 l^2}$$
方向沿$x$轴正方向

**Q点**：
$$E_1 = E_2 = \frac{1}{4\pi\varepsilon_0} \cdot \frac{q}{(2l)^2} = \frac{q}{16\pi\varepsilon_0 l^2}$$
$$E = E_y = \frac{q}{16\pi\varepsilon_0 l^2}$$
方向沿$y$轴负方向

![题2图示](2.1电场强度/4.png)

## 2. 求电场强度—连续型

### 解题方法

$$dE = \frac{1}{4\pi\varepsilon_0} \cdot \frac{dq}{r^2}$$
$$E = \int dE = \int \frac{1}{4\pi\varepsilon_0} \cdot \frac{dq}{r^2}$$

常用积分公式：
$$\int xdx = \frac{1}{2}x^2 + C$$
$$\int dx = x + C$$

### 例题

**题1**：均匀带电细棒，棒长$L$，电荷线密度$\lambda$，求：棒的延长线上与棒的右端相距$d$处的场强。

![题1图示](2.1电场强度/5.png)

**解**：在带电棒上取一线元$dx$，则$dx$所带的电荷量：$dq = \lambda \cdot dx$

在$P$处：
$$dE = \frac{1}{4\pi\varepsilon_0} \cdot \frac{\lambda \cdot dx}{(L + d - x)^2}$$

$$E = \int dE = \int_{0}^{L} \frac{1}{4\pi\varepsilon_0} \cdot \frac{\lambda}{(L + d - x)^2} dx$$
$$= \frac{\lambda}{4\pi\varepsilon_0} \cdot \frac{1}{(L + d - x)} \bigg|_{0}^{L} = \frac{\lambda}{4\pi\varepsilon_0} \left( \frac{1}{d} - \frac{1}{L + d} \right)$$

![题1解答1](2.1电场强度/6.png)

另一种坐标设定（原点在棒右端）：
$$dE = \frac{1}{4\pi\varepsilon_0} \cdot \frac{\lambda \cdot dx}{(x + d)^2}$$

$$E = \int_{0}^{L} \frac{1}{4\pi\varepsilon_0} \cdot \frac{\lambda}{(x + d)^2} dx$$
$$= \frac{\lambda}{4\pi\varepsilon_0} \cdot \frac{-1}{(x + d)} \bigg|_{0}^{L} = \frac{\lambda}{4\pi\varepsilon_0} \left( \frac{1}{d} - \frac{1}{L + d} \right)$$

![题1解答2](2.1电场强度/7.png)

---

**题2**：一个半径为$R$的均匀带正电半圆环，电荷线密度为$\lambda$，求环心处$O$点的场强和方向。

**解**：在半圆环上任取线元$dl$，$dl = Rd\theta$，所带电量：$dq = \lambda \cdot dl = \lambda \cdot Rd\theta$

在$O$点产生的场强：
$$dE = \frac{1}{4\pi\varepsilon_0} \cdot \frac{\lambda \cdot dl}{R^2} = \frac{\lambda}{4\pi\varepsilon_0 R^2} dl$$

分量分解：
$$dE_x = dE \cdot \sin\theta = \frac{\lambda}{4\pi\varepsilon_0 R^2} \sin\theta \cdot Rd\theta = \frac{\lambda}{4\pi\varepsilon_0 R} \sin\theta d\theta$$
$$dE_y = dE \cdot \cos\theta = \frac{\lambda}{4\pi\varepsilon_0 R} \cos\theta d\theta$$

积分：
$$E_x = \int_{0}^{\pi} \frac{\lambda}{4\pi\varepsilon_0 R} \sin\theta d\theta = \frac{\lambda}{2\pi\varepsilon_0 R}$$
$$E_y = \int_{0}^{\pi} \frac{\lambda}{4\pi\varepsilon_0 R} \cos\theta d\theta = 0$$

$$E = E_x = \frac{\lambda}{2\pi\varepsilon_0 R}$$
方向朝$x$正方向

![题2图示](2.1电场强度/8.png)

## 3. 求电场强度—结论型

### 常用结论汇总

| 带电体 | 场强公式 | 备注 |
|--------|----------|------|
| 点电荷 | $E = \frac{1}{4\pi\varepsilon_0} \cdot \frac{q}{r^2}$ | |
| 无限长均匀带电直线 | $E = \frac{\lambda}{2\pi\varepsilon_0 r}$ | $r$为到直线距离 |
| 无限大均匀带电平面 | $E = \frac{\sigma}{2\varepsilon_0}$ | 与距离无关 |
| 均匀带电圆柱面 | $E = 0$（$r < R$）<br>$E = \frac{\lambda}{2\pi\varepsilon_0 r}$（$r > R$） | 高斯推导 |
| 均匀带电球体 | $E = \frac{qr}{4\pi\varepsilon_0 R^3}$（$r < R$）<br>$E = \frac{q}{4\pi\varepsilon_0 r^2}$（$r > R$） | 高斯推导 |

![结论型公式汇总](2.1电场强度/9.png)

### 例题

**题1**：均匀带电"无限大"平面上的面电荷密度为$\sigma_0$，其场强与场点到带电平板的距离无关，其场强大小为______

**解**：$E = \frac{\sigma_0}{2\varepsilon_0}$

---

**题2**：真空中两个平行的"无限大"均匀带电平面，电荷面密度为$+\sigma$和$-2\sigma$，则$A, B, C$三个区域的场强分别为：

**解**：
- $A$区：$\vec{E}_A = \frac{\sigma}{2\varepsilon_0}\vec{i}$
- $B$区：$\vec{E}_B = \frac{3\sigma}{2\varepsilon_0}\vec{i}$
- $C$区：$\vec{E}_C = -\frac{\sigma}{2\varepsilon_0}\vec{i}$

![题2图示](2.1电场强度/10.png)

**题3**：一宽为$b$的无限长均匀带电平面薄板，其电荷面密度为$\sigma$，试求平板所在平面内，距薄板边缘为$a$处的电场强度。

**解**：薄板内任取一窄条，宽为$dx$，窄条可视为无限长带电线，线密度：$\lambda = \sigma dx$

无限长带电线在$P$点的场强：

$$E = \int_{-\frac{b}{2}}^{\frac{b}{2}} \frac{\sigma dx}{2\pi\varepsilon_0 \left(a + \frac{b}{2} - x\right)} = \frac{\sigma}{2\pi\varepsilon_0} \ln\frac{a + b}{a}$$

## 1. 电通量

### 电场线性质

(1) 电场线总是起自正电荷，终止于负电荷。

(2) 电场线不会自成闭合线，任意两条电场线也不会相交。

(3) 电场线密度大的地方，电场强度$E$越大。

![电场线图示](2.2电通量,高斯定理/2.png)

### 电通量公式

(1) **电通量**：$\Phi_e = E \cdot S$

(2) $E$和$S$必须是垂直关系

(3) 对于**曲面**，向外穿出为正，向内穿入为负

**三种情况**：
- 平面垂直电场：$\Phi_e = E \cdot S$
- 平面与电场成$\theta$角：$\Phi_e = E \cdot S \cdot \cos\theta$
- 曲面：$d\Phi_e = \vec{E} \cdot d\vec{S}$，$\Phi_e = \int d\Phi_e = \iint \vec{E} \cdot d\vec{S}$

![电通量公式图示](2.2电通量,高斯定理/3.png)

### 例题

**题1**：一电场强度为$\vec{E}$的均匀电场，$\vec{E}$的方向沿$x$轴正向，则通过图中一半径为$R$的半球面的电场强度通量为（ ）

A. $\frac{\pi R^2 E}{2}$ B. $0$ C. $2\pi R^2 E$ D. $\pi R^2 E$

**解**：选**B**（电场线穿入和穿出相等，总通量为0）

---

**题2**：如图，在电场强度$E$的匀强电场中，有一半径为$R$的半球面，场强$E$的方向与半球面对称轴平行，穿过此半球面的电通量为（ ）

A. $2\pi R^2 E$ B. $\sqrt{2}\pi R^2 E$ C. $\pi R^2 E$ D. $\frac{\pi R^2 E}{2}$

**解**：$\Phi_e = E \cdot S = \pi \cdot R^2 E$，选**C**

---

**题3**：有一半径为$R$的半球面如图所示，放在均匀电场中，通过半球面的电通量（ ）

A. $2\pi R^2 E$ B. $-\pi R^2 E$ C. $2\pi R^2 \cos\theta$ D. $-\pi R^2 E \cos\theta$

**解**：$\Phi_e = -E \cdot S \cos\theta = -\pi \cdot R^2 E \cos\theta$，选**D**

## 2. 静电场中的高斯定理

### 高斯定理内容

闭合曲面的电通量等于包含电荷量除以$\varepsilon_0$：

$$\Phi_e = \oiint \vec{E} \cdot d\vec{S} = \frac{1}{\varepsilon_0} \sum q_{内}$$

![高斯定理图示](2.2电通量,高斯定理/5.png)

### 例题

**题1**：求电荷量为$q$的均匀带电球壳内外场强分布。

**解**：由高斯定理：
$$\oiint \vec{E} \cdot d\vec{S} = E \cdot \oiint dS = E \cdot 4\pi r^2 = \frac{1}{\varepsilon_0} \sum q_{内}$$

$$\Rightarrow E = \frac{\sum q_{内}}{4\pi \varepsilon_0 r^2}$$

- $r < R$时：$\sum q_{内} = 0 \Rightarrow E = 0$
- $r > R$时：$\sum q_{内} = q \Rightarrow E = \frac{q}{4\pi \varepsilon_0 r^2}$

![题1图示](2.2电通量,高斯定理/6.png)

---

**题2**：半径为$R$的球体，均匀带电$q$，试求场强分布。

**解**：由高斯定理：
$$\oiint \vec{E} \cdot d\vec{S} = E \cdot 4\pi r^2 = \frac{1}{\varepsilon_0} \sum q_{内} \Rightarrow E = \frac{\sum q_{内}}{4\pi \varepsilon_0 r^2}$$

体密度：$\rho = \frac{q}{V} = \frac{q}{\frac{4}{3}\pi R^3} = \frac{3q}{4\pi R^3}$

- $r < R$时：$\sum q_{内} = \rho \cdot V_r = \frac{3q}{4\pi R^3} \cdot \frac{4}{3}\pi r^3 = \frac{qr^3}{R^3}$

$$E = \frac{qr^3/R^3}{4\pi \varepsilon_0 r^2} = \frac{qr}{4\pi \varepsilon_0 R^3}$$

- $r > R$时：$\sum q_{内} = q \Rightarrow E = \frac{q}{4\pi \varepsilon_0 r^2}$

![题2图示](2.2电通量,高斯定理/7.png)

---

**题3**：一半径为$R$的带电球体，其电荷密度$\rho = A \cdot r$（$A > 0$），试求球内外的场强分布。

**解**：由高斯定理：
$$\oiint \vec{E} \cdot d\vec{S} = E \cdot 4\pi r^2 = \frac{1}{\varepsilon_0} \sum q_{内} \Rightarrow E = \frac{\sum q_{内}}{4\pi \varepsilon_0 r^2}$$

$dV = 4\pi r^2 \cdot dr$，$dq = \rho \cdot dV = Ar \cdot 4\pi r^2 dr$

- $r < R$时：$\sum q_{内} = \int_0^r Ar \cdot 4\pi r^2 dr = \pi A r^4$

$$E = \frac{\pi A r^4}{4\pi \varepsilon_0 r^2} = \frac{A r^2}{4\varepsilon_0}$$

- $r > R$时：$\sum q_{内} = \int_0^R Ar \cdot 4\pi r^2 dr = \pi A R^4$

$$E = \frac{\pi A R^4}{4\pi \varepsilon_0 r^2} = \frac{A R^4}{4\varepsilon_0 r^2}$$

![题3图示](2.2电通量,高斯定理/8.png)

![题3解答](2.2电通量,高斯定理/9.png)

---

**题4**：求半径为$R$，线密度为$\lambda$的无限长均匀带电圆柱体内外场强分布。

**解**：由高斯定理：
$$\oiint \vec{E} \cdot d\vec{S} = E \cdot \oiint dS = E \cdot 2\pi r h = \frac{1}{\varepsilon_0} \sum q_{内}$$

$$\Rightarrow E = \frac{\sum q_{内}}{2\pi \varepsilon_0 r h}$$

- $r < R$时：$\sum q_{内} = \frac{\lambda h}{\pi R^2 h} \cdot \pi r^2 h = \frac{r^2}{R^2} \lambda h$

$$E = \frac{\frac{r^2}{R^2} \lambda h}{2\pi \varepsilon_0 r h} = \frac{\lambda r}{2\pi \varepsilon_0 R^2}$$

- $r > R$时：$\sum q_{内} = \lambda h$

$$E = \frac{\lambda h}{2\pi \varepsilon_0 r h} = \frac{\lambda}{2\pi \varepsilon_0 r}$$

**题5**：点电荷$q$位于一边长为$a$的立方体中心，试求：

**题10**：关于高斯定理的理解有下面几种说法，其中正确的是（ ）

B. 如果高斯面上$\vec{E}$处处不为零，则该面内必有电荷

C. 如果高斯面上$\vec{E}$处处为零，则该面内必无电荷

D. 如果高斯面内净电荷不为零，则通过该面的电通量必不为零

**解**：选**D**

### 高斯定理要点总结

(1) 电通量与高斯面面内电荷有关，与电荷的位置以及高斯面面外电荷无关

(2) $\sum q_{内}$是指高斯面内的净电荷（所有正负电荷的代数和）

## 1. 电势

### 基本概念和公式

**做功与路径无关** → 电场力是保守力 → 电势能

**电势能**：$W_M = \int_{M}^{\infty} \vec{F} \cdot d\vec{l} = \int_{M}^{\infty} q_0 \vec{E} \cdot d\vec{l}$

**电势零点**：可以自定义，一般默认无穷远处

**电势定义**：
$$V = \frac{W_M}{q_0} = \int_{r}^{\infty} \vec{E} \cdot d\vec{l} = \frac{q}{4\pi \varepsilon_0 r}$$

电势在数值上等于单位正电荷从该点沿任意路径到零势能点电场力做功。

### 求电势三种类型

① **离散型**：$V = \frac{q}{4\pi \varepsilon_0 r}$

② **连续型**：$dV = \frac{dq}{4\pi \varepsilon_0 r}$，$V = \int \frac{dq}{4\pi \varepsilon_0 r}$

③ **已知场强求电势**：$V = \int_{起点}^{\infty} \vec{E} \cdot d\vec{l}$

![电势基本概念](2.3电势,电势能/2.png)

### 例题：连续型

**题1**：一均匀带电半圆环，半径为$R$，电量为$+Q$，求环心处的电势。

**解**：带电圆环上取线元$dl$，则$dl$所带的电量：$dq = \frac{Q}{\pi R} \cdot dl$

在$O$点产生的电势：
$$dV = \frac{dq}{4\pi \varepsilon_0 r} = \frac{Q dl}{4\pi^2 \varepsilon_0 R^2}$$

$$V = \int dV = \int_{0}^{\pi R} \frac{Q dl}{4\pi^2 \varepsilon_0 R^2} = \frac{Q}{4\pi \varepsilon_0 R}$$

结论：圆环/半圆环/部分圆环，总带电量为$Q$，在圆心处的电势：$V_O = \frac{Q}{4\pi \varepsilon_0 R}$

![题1图示](2.3电势,电势能/3.png)

---

**题2**：一绝缘细棒弯成半径为$R$的1/4圆形环，使之均匀带正电，电荷线密度为$+\lambda$，设无穷远处为电势零点，则在1/4圆环圆心$O$处的电势为（ ）

A. $\frac{\lambda}{8\varepsilon_0}$ B. $\frac{\lambda}{\varepsilon_0}$ C. $\frac{\lambda}{2\varepsilon_0}$ D. $\frac{\lambda}{4\varepsilon_0}$

**解**：1/4圆形环带电量：$Q = \lambda \cdot \frac{1}{4} \cdot 2\pi R = \frac{1}{2}\pi R \lambda$

所以在$O$点的电势：
$$V = \frac{Q}{4\pi \varepsilon_0 R} = \frac{\frac{1}{2}\pi R \lambda}{4\pi \varepsilon_0 R} = \frac{\lambda}{8\varepsilon_0}$$

选**A**

![题2图示](2.3电势,电势能/4.png)

---

### 例题：已知场强求电势

**题1**：求电荷量为$q$的均匀带电球壳内外电势分布。

**解**：先由高斯定理求场强：
$$\oiint \vec{E} \cdot d\vec{S} = E \cdot 4\pi r^2 = \frac{1}{\varepsilon_0} \sum q_{内} \Rightarrow E = \frac{\sum q_{内}}{4\pi \varepsilon_0 r^2}$$

- $r < R$时：$\sum q_{内} = 0 \Rightarrow E_1 = 0$
- $r > R$时：$\sum q_{内} = q \Rightarrow E_2 = \frac{q}{4\pi \varepsilon_0 r^2}$

再由场强求电势：

- $r < R$时：$V = \int_{起点}^{\infty} \vec{E} \cdot d\vec{l} = \int_{r}^{R} E_1 dr + \int_{R}^{\infty} E_2 dr = \int_{r}^{R} 0 dr + \int_{R}^{\infty} \frac{q}{4\pi \varepsilon_0 r^2} dr = \frac{q}{4\pi \varepsilon_0 R}$

- $r > R$时：$V = \int_{起点}^{\infty} \vec{E} \cdot d\vec{l} = \int_{r}^{\infty} E_2 dr = \int_{r}^{\infty} \frac{q}{4\pi \varepsilon_0 r^2} dr = \frac{q}{4\pi \varepsilon_0 r}$

![题1图示](2.3电势,电势能/5.png)

---

**题2**：如图所示，在半径为$R_1$和$R_2$的两个同心球面上分别均匀带电$q_1$和$q_2$，求三个区域内的电势分布。

**解**：

(1) 先求场强分布：
$$\oiint \vec{E} \cdot d\vec{S} = E \cdot 4\pi r^2 = \frac{1}{\varepsilon_0} \sum q_{内} \Rightarrow E = \frac{\sum q_{内}}{4\pi \varepsilon_0 r^2}$$

- $r < R_1$时：$\sum q_{内} = 0 \Rightarrow E_1 = 0$
- $R_1 < r < R_2$时：$\sum q_{内} = q_1 \Rightarrow E_2 = \frac{q_1}{4\pi \varepsilon_0 r^2}$
- $r > R_2$时：$\sum q_{内} = q_1 + q_2 \Rightarrow E_3 = \frac{q_1 + q_2}{4\pi \varepsilon_0 r^2}$

(2) 电势分布：

- $r < R_1$时：
$$V_1 = \int_{r}^{R_1} 0 dr + \int_{R_1}^{R_2} \frac{q_1}{4\pi \varepsilon_0 r^2} dr + \int_{R_2}^{\infty} \frac{q_1 + q_2}{4\pi \varepsilon_0 r^2} dr = \frac{1}{4\pi \varepsilon_0} \left( \frac{q_2}{R_2} + \frac{q_1}{R_1} \right)$$

- $R_1 < r < R_2$时：
$$V_2 = \int_{r}^{R_2} \frac{q_1}{4\pi \varepsilon_0 r^2} dr + \int_{R_2}^{\infty} \frac{q_1 + q_2}{4\pi \varepsilon_0 r^2} dr = \frac{1}{4\pi \varepsilon_0} \left( \frac{q_1}{r} + \frac{q_2}{R_2} \right)$$

- $r > R_2$时：
$$V_3 = \int_{r}^{\infty} \frac{q_1 + q_2}{4\pi \varepsilon_0 r^2} dr = \frac{q_1 + q_2}{4\pi \varepsilon_0 r}$$

![题2图示](2.3电势,电势能/6.png)

---

**题3**：半径为$R_1$和$R_2$的两个无限长同轴圆柱面，单位长度上分别带有电量$\lambda$和$-\lambda$，试求：(1) 空间场强分布；(2) 两圆柱面之间的电势差。

**解**：

(1) 由高斯定理：
$$\oiint \vec{E} \cdot d\vec{S} = E \cdot 2\pi r h = \frac{1}{\varepsilon_0} \sum q_{内} \Rightarrow E = \frac{\sum q_{内}}{2\pi \varepsilon_0 r h}$$

- $r < R_1$时：$\sum q_{内} = 0 \Rightarrow E_1 = 0$
- $R_1 < r < R_2$时：$\sum q_{内} = \lambda h \Rightarrow E_2 = \frac{\lambda}{2\pi \varepsilon_0 r}$
- $r > R_2$时：$\sum q_{内} = \lambda h - \lambda h = 0 \Rightarrow E_3 = 0$

(2) 两圆柱面之间的电势差：
$$V_{AB} = \int_{R_1}^{R_2} \vec{E}_2 \cdot d\vec{r} = \int_{R_1}^{R_2} \frac{\lambda}{2\pi \varepsilon_0 r} dr = \frac{\lambda}{2\pi \varepsilon_0} \ln \frac{R_2}{R_1}$$

![题3图示](2.3电势,电势能/7.png)

---

**题4**：一电荷$q = 10^{-9}C$，$A, B, C$三点分别距离该点电荷10cm, 20cm, 30cm。若选$B$点电势为零，则$A$点的电势为______，$C$点的电势为______。

**解**：

$$V_A = \int_{r_A}^{r_B} \vec{E} \cdot d\vec{l} = \int_{r_A}^{r_B} \frac{q}{4\pi \varepsilon_0 r^2} dr = \frac{q}{4\pi \varepsilon_0} \left( \frac{1}{r_A} - \frac{1}{r_B} \right)$$
$$= \frac{10^{-9}}{4\pi \times 8.85 \times 10^{-12}} \left( \frac{1}{0.1} - \frac{1}{0.2} \right) = 45\ V$$

$$V_C = \int_{r_C}^{r_B} \vec{E} \cdot d\vec{l} = \int_{r_C}^{r_B} \frac{q}{4\pi \varepsilon_0 r^2} dr = \frac{q}{4\pi \varepsilon_0} \left( \frac{1}{r_C} - \frac{1}{r_B} \right)$$
$$= \frac{10^{-9}}{4\pi \times 8.85 \times 10^{-12}} \left( \frac{1}{0.3} - \frac{1}{0.2} \right) = -15\ V$$

## 2. 电势能

### 基本概念和公式

**电势能** = 电荷 × 电势 = 电场力做功

$$W_M = q_0 V = \int_{M}^{零势能点} \vec{F} \cdot d\vec{l}$$

**电场力做正功** = **电势能减小**

$$A = -(W_2 - W_1)$$

![电势能基本概念](2.3电势,电势能/9.png)

### 例题

**题1**：如图所示，在$A、B$两点处有电量分别为$+q、-q$的点电荷，$A、B$间的距离为$2R$，现将另一正试验点电荷$q_0$从$O$点经半圆弧移动到$C$点，电场力所做的功为______。

**解**：

$O$点电势：$V_O = \frac{q}{4\pi \varepsilon_0 R} + \frac{-q}{4\pi \varepsilon_0 R} = 0$

$C$点电势：$V_C = \frac{q}{4\pi \varepsilon_0 \cdot 3R} + \frac{-q}{4\pi \varepsilon_0 R} = -\frac{q}{6\pi \varepsilon_0 R}$

电势能变化：$W_2 - W_1 = q_0 V_C - q_0 V_O = -\frac{q q_0}{6\pi \varepsilon_0 R}$

故电场力做功：$A = -(W_2 - W_1) = \frac{q q_0}{6\pi \varepsilon_0 R}$

![题1图示](2.3电势,电势能/10.png)

---

**题2**：一电量为$q$的点电荷位于圆心$O$处，$A, B, C, D$为同一圆周上的四点，现将一试验电荷从$A$点分别移动到$B, C, D$各点，则（ ）

A. 从$A$到$B$，电场力做功最大

B. 从$A$到各点，电场力做功相等

C. 从$A$到$D$，电场力做功最大

D. 从$A$到$C$，电场力做功最大

**解**：同一圆周上各点电势相等：$V_A = V_B = V_C = V_D$

电势能相等：$q_0 V_A = q_0 V_B = q_0 V_C = q_0 V_D$

所以从$A$到各点，电势能变化为0，电场力做功相等。选**B**

## 3. 电场和电势关系

### 基本关系

(1) $E = 0 \nRightarrow V = 0$，$E$大小 $\nRightarrow V$大小

(2) 电场线密的地方电场强度越大

(3) **电势沿电场线方向减小**

(4) 某点电势随电势零点不同而不同

(5) $\vec{E} = -\left( \frac{\partial V}{\partial x}, \frac{\partial V}{\partial y}, \frac{\partial V}{\partial z} \right)$

### 例题

**题1**：描述静电场性质的两个基本物理量是______。

**解**：电场强度和电势

## 2. 导体中的电场和电势

### 例题

**题1**：有一外半径为$R_3$，内半径为$R_2$的金属球壳，在球壳内放一半径为$R_1$的同心金属球，若使金属球带有$q$的正电荷。求：(1) 电荷分布；(2) 电场分布；(3) 电势分布。

**解**：

(1) **电荷分布**：
- 金属球表面：$+q$
- 球壳内表面：$-q$
- 球壳外表面：$+q$

(2) **电场分布**（由高斯定理）：
$$\oiint \vec{E} \cdot d\vec{S} = E \cdot 4\pi r^2 = \frac{1}{\varepsilon_0} \sum q_{内} \Rightarrow E = \frac{\sum q_{内}}{4\pi \varepsilon_0 r^2}$$

- $r < R_1$时：$\sum q_{内} = 0 \Rightarrow E_1 = 0$
- $R_1 < r < R_2$时：$\sum q_{内} = q \Rightarrow E_2 = \frac{q}{4\pi \varepsilon_0 r^2}$
- $R_2 < r < R_3$时：$\sum q_{内} = q - q = 0 \Rightarrow E_3 = 0$
- $r > R_3$时：$\sum q_{内} = q - q + q = q \Rightarrow E_4 = \frac{q}{4\pi \varepsilon_0 r^2}$

(3) **电势分布**：

- $r < R_1$时：
$$V = \frac{q}{4\pi \varepsilon_0 R_1} - \frac{q}{4\pi \varepsilon_0 R_2} + \frac{q}{4\pi \varepsilon_0 R_3} = \frac{q}{4\pi \varepsilon_0} \left( \frac{1}{R_1} - \frac{1}{R_2} + \frac{1}{R_3} \right)$$

- $R_1 < r < R_2$时：
$$V = \frac{q}{4\pi \varepsilon_0 r} - \frac{q}{4\pi \varepsilon_0 R_2} + \frac{q}{4\pi \varepsilon_0 R_3} = \frac{q}{4\pi \varepsilon_0} \left( \frac{1}{r} - \frac{1}{R_2} + \frac{1}{R_3} \right)$$

- $R_2 < r < R_3$时：
$$V = \frac{q}{4\pi \varepsilon_0 r} - \frac{q}{4\pi \varepsilon_0 r} + \frac{q}{4\pi \varepsilon_0 R_3} = \frac{q}{4\pi \varepsilon_0 R_3}$$

- $r > R_3$时：
$$V = \frac{q}{4\pi \varepsilon_0 r} - \frac{q}{4\pi \varepsilon_0 r} + \frac{q}{4\pi \varepsilon_0 r} = \frac{q}{4\pi \varepsilon_0 r}$$

## 1. 电容器

### 基本概念和公式

**电容定义**：$C = \frac{q}{U}$，单位：$F$（法拉），$1\mu F = 10^{-6}F$，$1pF = 10^{-12}F$

**关键要点**：

(1) 电容器是由导体构成，电荷量等值异号，分布在极板内侧

(2) $C = \frac{q}{U}$，$q$代表一侧的电荷量取正，$U$代表极板间电压

(3) 极板间电场强度：$E = \frac{\sigma}{\varepsilon_0} = \frac{U}{d}$，电势差：$U = \frac{q}{C} = E \cdot d$

(4) 极板间相互作用力：$F = \frac{1}{2} E \cdot q$

(5) 含介质：$C = \varepsilon_r C_0$，$E = \frac{E_0}{\varepsilon_r}$，$\varepsilon = \varepsilon_0 \cdot \varepsilon_r$

**电介质参数**：
- $\varepsilon$：介电常量（电容率）
- $\varepsilon_0$：真空中介电常量（真空中电容率）
- $\varepsilon_r$：相对介电常量（相对电容率），$\varepsilon_r \geq 1$，真空中$\varepsilon_r = 1$

![电容器基本概念](2.5电容器/2.png)

### 常见电容器电容公式

| 电容器类型 | 真空中电容 | 含介质$\varepsilon_r$电容 |
|------------|------------|--------------------------|
| **平行板电容器** | $C = \frac{\varepsilon_0 S}{d}$ | $C = \frac{\varepsilon_0 \varepsilon_r S}{d}$ |
| **圆柱形电容器** | $C = \frac{2\pi \varepsilon_0 l}{\ln R_B / R_A}$ | $C = \frac{2\pi \varepsilon_0 \varepsilon_r l}{\ln R_B / R_A}$ |
| **球形电容器** | $C = 4\pi \varepsilon_0 \frac{R_A R_B}{R_B - R_A}$ | $C = 4\pi \varepsilon_0 \varepsilon_r \frac{R_A R_B}{R_B - R_A}$ |
| **孤立导体电容器** | $C = 4\pi \varepsilon_0 R_A$ | $C = 4\pi \varepsilon_0 \varepsilon_r R_A$ |

![常见电容器类型](2.5电容器/3.png)
        

### 电容器串并联

**串联**：$\frac{1}{C} = \frac{1}{C_1} + \frac{1}{C_2}$

**并联**：$C = C_1 + C_2$

### 例题

**题1**：求面积为$S$，两极板间距离为$d$的平行板电容器的电容。

**解**：
电荷 $q = \sigma \cdot S$

电势差：$U = E \cdot d = \frac{\sigma}{\varepsilon_0} \cdot d$

电容：$C = \frac{q}{U} = \frac{\sigma S}{\frac{\sigma}{\varepsilon_0} \cdot d} = \frac{\varepsilon_0 S}{d}$

含介质时：$C = \frac{\varepsilon_0 \varepsilon_r S}{d}$

结论：电容大小只与极板大小、形状、相对位置以及电介质有关

$S' \to 2S$，$d' \to 3d$

**题6**：平行板电容器两板间距离为$d$，极板面积为$S$，在真空时的电容、自由电荷面密度、电势差、电场强度的大小分别用$C_0, \sigma_0, U_0, E_0$表示。

(1) 如充电后与电源断开，将$\varepsilon_r$的均匀介质充满电容器，则：

$C =$______，$\sigma =$______，$U =$______，$E =$______

(2) 与电源保持联接，将$\varepsilon_r$的均匀介质充满电容器，则：

$C =$______，$\sigma =$______，$U =$______，$E =$______

(1) 电荷量$Q$不变：
$$C = \varepsilon_r C_0$$
$$\sigma = \frac{Q}{S} = \sigma_0$$
$$U = \frac{Q}{C} = \frac{Q}{\varepsilon_r C_0} = \frac{U_0}{\varepsilon_r}$$
$$E = \frac{U}{d} = \frac{U_0}{\varepsilon_r d} = \frac{E_0}{\varepsilon_r}$$

(2) 电压不变$U = U_0$：
$$C = \varepsilon_r C_0$$
$$\sigma = \frac{Q}{S} = \frac{C \cdot U}{S} = \frac{\varepsilon_r C_0 \cdot U}{S} = \frac{\varepsilon_r Q_0}{S} = \varepsilon_r \sigma_0$$
$$U = U_0$$
$$E = \frac{U}{d} = \frac{U_0}{d} = E_0$$

## 1. 电介质高斯定理

### 基本概念和公式

**电介质中的高斯定理**：$\oiint \vec{D} \cdot d\vec{S} = \sum q_{内}$，适用：含介质和真空

**电位移**：$D = \varepsilon_0 \varepsilon_r E$，$\sum q_{内}$为自由电荷代数和

**真空中**：$\varepsilon_r = 1$，$D = \varepsilon_0 E$

**电介质中的场强**：$E = E_0 - E' = \frac{E_0}{\varepsilon_r}$

**极化电荷面密度**：$\sigma' = \left( 1 - \frac{1}{\varepsilon_r} \right) \sigma_0$

![电介质高斯定理](2.6电介质、电场能/2.png)

### 例题

**题1**：在半径为$R_1$的金属球之外包有一层外半径为$R_2$的均匀电介质球壳，介质的相对介电常数为$\varepsilon_r$，金属球带电$Q$，试求：(1) 电介质内外的场强；(2) 电介质内外的电势。

**解**：

(1) 由电介质高斯定理：$\oiint \vec{D} \cdot d\vec{S} = D \cdot 4\pi r^2 = \sum q_{内} \Rightarrow D = \frac{\sum q_{内}}{4\pi r^2} \Rightarrow E = \frac{D}{\varepsilon_0 \varepsilon_r}$

- $r < R_1$时：$\sum q_{内} = 0 \Rightarrow D = 0 \Rightarrow E_1 = 0$
- $R_1 < r < R_2$时：$\sum q_{内} = Q \Rightarrow D = \frac{Q}{4\pi r^2} \Rightarrow E_2 = \frac{Q}{4\pi \varepsilon_0 \varepsilon_r r^2}$
- $r > R_2$时：$\sum q_{内} = Q \Rightarrow D = \frac{Q}{4\pi r^2} \Rightarrow E_3 = \frac{Q}{4\pi \varepsilon_0 r^2}$

(2) 电势分布：

- $r < R_1$时：
$$V = \int_{R_1}^{R_2} E_2 dr + \int_{R_2}^{\infty} E_3 dr = \int_{R_1}^{R_2} \frac{Q}{4\pi \varepsilon_0 \varepsilon_r r^2} dr + \int_{R_2}^{\infty} \frac{Q}{4\pi \varepsilon_0 r^2} dr = \frac{Q}{4\pi \varepsilon_0 \varepsilon_r} \left( \frac{1}{R_1} - \frac{1}{R_2} \right) + \frac{Q}{4\pi \varepsilon_0 R_2}$$

- $R_1 < r < R_2$时：
$$V = \int_{r}^{R_2} E_2 dr + \int_{R_2}^{\infty} E_3 dr = \int_{r}^{R_2} \frac{Q}{4\pi \varepsilon_0 \varepsilon_r r^2} dr + \int_{R_2}^{\infty} \frac{Q}{4\pi \varepsilon_0 r^2} dr = \frac{Q}{4\pi \varepsilon_0 \varepsilon_r} \left( \frac{1}{r} - \frac{1}{R_2} \right) + \frac{Q}{4\pi \varepsilon_0 R_2}$$

- $r > R_2$时：
$$V = \int_{r}^{\infty} E_3 dr = \int_{r}^{\infty} \frac{Q}{4\pi \varepsilon_0 r^2} dr = \frac{Q}{4\pi \varepsilon_0 r}$$

![题1图示](2.6电介质、电场能/3.png)

---

**题2**：一圆柱形电容器由半径为$R_1$的导线和与它同轴的导体圆筒构成，圆筒长为$l$，内半径为$R_2$，导线与圆筒间充满相对电容率$\varepsilon_r$的电介质，设沿轴线单位长度上导线的电量为$\lambda$，圆筒的电量为$-\lambda$，略去边缘效应，求：(1) 电介质中电位移$D$，场强$E$；(2) 两极板的电势差。

**解**：

(1) $\oiint \vec{D} \cdot d\vec{S} = D \cdot 2\pi r h = \sum q_{内} \Rightarrow D = \frac{\sum q_{内}}{2\pi r h} \Rightarrow E = \frac{D}{\varepsilon_0 \varepsilon_r}$

$R_1 < r < R_2$时：$\sum q_{内} = \lambda h$

$$\Rightarrow D = \frac{\lambda h}{2\pi r h} = \frac{\lambda}{2\pi r} \Rightarrow E = \frac{\lambda}{2\pi \varepsilon_0 \varepsilon_r r}$$

(2) 两极板间电势差：
$$U_{AB} = \int_{R_1}^{R_2} \vec{E} \cdot d\vec{r} = \int_{R_1}^{R_2} \frac{\lambda}{2\pi \varepsilon_0 \varepsilon_r r} dr = \frac{\lambda}{2\pi \varepsilon_0 \varepsilon_r} \ln \frac{R_2}{R_1}$$

## 2. 电场能

### 基本概念和公式

**电场能密度**（单位：$J/m^3$）：
$$w_e = \frac{1}{2} D E = \frac{1}{2} \varepsilon_0 \varepsilon_r E^2$$

**电场能**：
$$W = \int_V w_e dV$$

**电容器储存的电场能**：
$$W = \frac{Q^2}{2C} = \frac{1}{2} C (V_1 - V_2)^2 = \frac{1}{2} Q (V_1 - V_2)$$

### 例题

**题1**：在相对电容率$\varepsilon_r = 4$的各向同性均匀电介质中，与能量密度$w_e = 2 \times 10^6 J/m^3$相应的电场强度大小$E =$______$N/C$

**解**：由$w_e = \frac{1}{2} \varepsilon_0 \varepsilon_r E^2$：
$$E = \sqrt{\frac{2w_e}{\varepsilon_0 \varepsilon_r}} = \sqrt{\frac{2 \times 2 \times 10^6}{8.85 \times 10^{-12} \times 4}} = 3.36 \times 10^8 N/C$$

---

**题2**：一个$3\mu F$的电容被接到$12V$的电源，则储存在电容器中的能量为______

**解**：$3\mu F = 3 \times 10^{-6}F$
$$W = \frac{1}{2} C (V_1 - V_2)^2 = \frac{1}{2} \times 3 \times 10^{-6} \times 12^2 = 2.16 \times 10^{-4} J$$

---

**题3**：有一半径为$R$的带电导体球，带电量为$q$，放在相对电容率为$\varepsilon_r$的无限大均匀介质中，则此系统的电场能量为（ ）

A. $\frac{q^2}{8\pi \varepsilon_0 \varepsilon_r R}$

B. $\frac{q}{4\pi \varepsilon_0 \varepsilon_r R^2}$

C. $\frac{q}{8\pi \varepsilon_0 \varepsilon_r R^2}$

D. $\frac{q^2}{4\pi \varepsilon_0 \varepsilon_r R^2}$

**解**：$C = 4\pi \varepsilon_0 \varepsilon_r R$
$$W = \frac{Q^2}{2C} = \frac{q^2}{2 \times 4\pi \varepsilon_0 \varepsilon_r R} = \frac{q^2}{8\pi \varepsilon_0 \varepsilon_r R}$$

选**A**

## 1. 毕奥-萨伐尔定律

### 基本概念

**毕奥-萨伐尔定律**（毕萨定理）：描述电流元在空间产生的磁感应强度

$$dB = \frac{\mu_0}{4\pi} \cdot \frac{Idl \cdot \sin\theta}{r^2}$$

$$B = \int dB = \frac{\mu_0}{4\pi} \int \frac{Idl \sin\theta}{r^2}$$

**单位**：$T$（特斯拉）

**真空中磁导率**：$\mu_0 = 4\pi \times 10^{-7} T \cdot m/A$

### 磁场线图示

- 直线电流：同心圆磁场线
- 环形电流：类似条形磁铁的磁场线
- 螺线管：内部匀强磁场

**符号约定**：
- $\otimes$：垂直纸面向内
- $\odot$：垂直纸面向外

![磁场线图示](2.7磁感应强度/2.png)

### 毕奥-萨伐尔定律基本公式

![毕奥-萨伐尔定律公式](2.7磁感应强度/3.png)

### 例题：载流直导线

**题1**：在长为$L$的一段载流直导线中，通有电流$I$，求距离导线为$a$处一点$P$的磁感应强度。

**解**：任取一电流元$Idl$

$$dB = \frac{\mu_0}{4\pi} \cdot \frac{Idl \sin\theta}{r^2}$$

$$B = \int dB = \frac{\mu_0}{4\pi} \int \frac{Idl \sin\theta}{r^2}$$

通过变量替换：$r = \frac{a}{\sin\theta}$，$dl = a \csc^2\theta d\theta$

$$B = \frac{\mu_0 I}{4\pi a} \int_{\theta_1}^{\theta_2} \sin\theta d\theta = \frac{\mu_0 I}{4\pi a} (\cos\theta_1 - \cos\theta_2)$$

## 2. 安培环路定理

### 基本概念和公式

**安培环路定理**：
$$\oint \vec{B} \cdot d\vec{l} = \mu_0 \sum I_{内}$$

**关键要点**：

(1) 安培环路定理只与环路内电流有关，与电流位置以及环路外电流无关

(2) $\sum I_{内}$是指环路内的净电流（所有电流的代数和）

(3) 环路上的磁感应强度$B$，不仅由环路内电流影响，还由环路外电流影响

![安培环路定理](2.7磁感应强度/10.png)

### 例题

**题1**：已知半径为$R$的铜线，通过电流为$I$，电流在导线横截面上均匀分布，求导线内外磁感应强度的分布？

**解**：由$\oint \vec{B} \cdot d\vec{l} = B \cdot \oint dl = B \cdot 2\pi r = \mu_0 \sum I_{内} \Rightarrow B = \frac{\mu_0 \sum I_{内}}{2\pi r}$

- $r < R$时：$\sum I_{内} = \frac{I}{\pi R^2} \cdot \pi r^2 = \frac{Ir^2}{R^2}$

$$B = \frac{\mu_0 Ir}{2\pi R^2}$$

- $r > R$时：$\sum I_{内} = I$

$$B = \frac{\mu_0 I}{2\pi r}$$

方向沿逆时针方向

## 1. 磁通量、高斯定理

### 基本概念和公式

**磁通量**：$\Phi_m = B \cdot S$，单位：$Wb$（韦伯）

**三种情况**：

(1) 平面垂直磁场：$\Phi_m = B \cdot S$

(2) 平面与磁场成$\theta$角：$\Phi_m = B \cdot S \cdot \cos\theta$

(3) 曲面：$d\Phi_m = \vec{B} \cdot d\vec{S}$，$\Phi_m = \int d\Phi_m = \iint \vec{B} \cdot d\vec{S}$

**关键要点**：

(1) $B$和$S$必须是垂直关系

(2) 对于曲面，向外穿出为正，向内穿入为负

(3) **磁场中高斯定理**：$\Phi_m = \oiint \vec{B} \cdot d\vec{S} = 0$，沿闭合曲面积分为零：穿进等于穿出

![磁通量和高斯定理](2.8磁通量、高斯定理/2.png)

### 例题

**题1**：如图所示，在磁感应强度为$\vec{B}$的均匀磁场中作一半径为$r$的半球面$S$，则通过半球面$S$的磁通量为（ ）

A. $2\pi r^2 B$ B. $-\pi r^2 B$ C. $-2\pi r B$ D. $\pi r^2 B$

**解**：$\Phi_m = -B \cdot S = -B \cdot \pi r^2$，选**B**

![题1图示](2.8磁通量、高斯定理/3.png)

---

**题2**：在稳恒磁场中，穿过任一闭合曲面的总磁通量必然为______

**解**：$0$（磁场高斯定理）

---

**题3**：一个密绕细长螺线管，每米长度上绕有1000匝细导线，螺线管的横截面积为$0.001m^2$。当在螺线管中通入10A的电流时，它的横截面上的磁通量为______$Wb$（$\mu_0 = 4\pi \times 10^{-7} T \cdot m/A$）

**解**：
$$B = \mu_0 nI = 4\pi \times 10^{-7} \times 1000 \times 10 = 1.256 \times 10^{-2} T$$

$$\Phi_m = B \cdot S = 1.256 \times 10^{-2} \times 0.001 = 1.256 \times 10^{-5} Wb$$

**题4**：如图，一无限长直导线通以电流$I$，若有一矩形导体线框与直导线共面且距导线为$a$，试求通过矩形导体线框的磁通量。

## 1. 安培力

### 基本概念和公式

**安培力**：$F = B \cdot I \cdot L$，条件：$B \perp I \perp L$

**一般情况**：$F = B \cdot I \cdot L \cdot \sin\alpha$（$\alpha$为电流方向与磁场方向夹角）

**电流元受力**：$dF = BIdl$，$F = \int dF$

**右手定则**：掌心向里，四指指向电流方向，大拇指指向受力方向

![安培力基本概念](2.9安培力、磁力矩、洛伦兹力/2.png)

### 例题

**题1**：如图所示，一根长直导线载有电流$I_1$，矩形回路载有电流$I_2$，两者共面，试计算：作用在回路各边上的安培力以及线圈所受合外力。

**解**：

- $AB$段：$F_1 = B \cdot I \cdot L = \frac{\mu_0 I_1}{2\pi a} \cdot I_2 \cdot l = \frac{\mu_0 I_1 I_2 l}{2\pi a}$，朝左
- $BC$段：$dF = B \cdot I \cdot dx = \frac{\mu_0 I_1}{2\pi x} I_2 dx$，$F_2 = \int dF = \frac{\mu_0 I_1 I_2}{2\pi} \ln \frac{a+b}{a}$，朝上
- $CD$段：$F_3 = B \cdot I \cdot L = \frac{\mu_0 I_1}{2\pi (a+b)} \cdot I_2 \cdot l = \frac{\mu_0 I_1 I_2 l}{2\pi (a+b)}$，朝右
- $DA$段：$F_4 = F_2 = \frac{\mu_0 I_1 I_2}{2\pi} \ln \frac{a+b}{a}$，朝下

合力：$F = F_1 - F_3 = \frac{\mu_0 I_1 I_2 l}{2\pi} \left( \frac{1}{a} - \frac{1}{a+b} \right)$

![题1图示](2.9安培力、磁力矩、洛伦兹力/3.png)

---

**题2**：图示表示一段半圆形导线，通有电流$I$，圆的半径为$R$，放在均匀磁场$B$中，磁场与导线平面垂直，求磁场作用在半圆形导线上的安培力$F =$______。

**解**：$F = B \cdot I \cdot L = B \cdot I \cdot 2R = 2BIR$

结论：任意形状的载流导线在均匀磁场中所受安培力等于连接导线两端的直导线所受的安培力

## 2. 磁矩、磁力矩

### 基本概念和公式

**磁矩**：$p_m = I \cdot S$，单位：$A \cdot m^2$

**磁力矩**：$M = B p_m \sin\theta$（$\theta$为$B$和$p_m$夹角）

**特殊情况**：
- $\theta = \frac{\pi}{2}$时，磁力矩最大：$M_{max} = BIS$
- $\theta = 0$时，磁力矩最小：$M_{min} = 0$

**磁力矩做功**：$A = I \Delta \Phi_m$

![磁矩、磁力矩](2.9安培力、磁力矩、洛伦兹力/5.png)

**解**：$p_m = I \cdot S = I \cdot \pi R^2 = 10 \times 3.14 \times 0.1^2 = 0.314 A \cdot m^2$

## 1. 磁介质中安培环路定理

### 基本概念和公式

**磁介质中安培环路定理**：$\oint \vec{H} \cdot d\vec{l} = \sum I_{内}$，适用介质和真空

**真空中安培环路定理**：$\oint \vec{B} \cdot d\vec{l} = \mu_0 \sum I_{内}$

**磁场强度**：$H = \frac{B}{\mu_0 \mu_r} = \frac{B}{\mu}$

**磁感应强度与磁场强度关系**：$B = \mu_0 \mu_r H = \mu H$

**磁导率**：
- $\mu$：磁导率
- $\mu_0$：真空中磁导率
- $\mu_r$：相对磁导率，$\mu_r = \frac{B}{B_0}$

**三种磁介质**：
- 顺磁质：$\mu_r > 1$
- 抗磁质：$\mu_r < 1$
- 铁磁质：$\mu_r \gg 1$

**真空中相对磁导率**：$\mu_r = 1$，$H = \frac{B}{\mu_0}$

![磁介质中安培环路定理](2.10磁介质、磁场能/1.png)

### 例题

**题1**：长直圆柱形铜导线，外面包一层相对磁导率为$\mu_r$的圆筒形磁介质。导线半径为$R_1$，磁介质的半径为$R_2$，导线内有均匀分布的电流$I$通过，铜的相对磁导率可取1，求导线和介质内外的磁场强度$H$和磁感应强度$B$的分布。

**解**：由$\oint \vec{H} \cdot d\vec{l} = H \cdot 2\pi r = \sum I_{内} \Rightarrow H = \frac{\sum I_{内}}{2\pi r}$，$B = \mu_0 \mu_r H$

- $r < R_1$时（导线内部，$\mu_r = 1$）：
$$\sum I_{内} = \frac{I}{\pi R_1^2} \cdot \pi r^2 = \frac{Ir^2}{R_1^2}$$
$$H = \frac{Ir}{2\pi R_1^2}$$
$$B = \frac{\mu_0 Ir}{2\pi R_1^2}$$

- $R_1 < r < R_2$时（磁介质内部）：
$$\sum I_{内} = I$$
$$H = \frac{I}{2\pi r}$$
$$B = \frac{\mu_0 \mu_r I}{2\pi r}$$

- $r > R_2$时（介质外部，真空）：
$$\sum I_{内} = I$$
$$H = \frac{I}{2\pi r}$$
$$B = \frac{\mu_0 I}{2\pi r}$$

## 2. 磁场能量

### 基本概念和公式

**磁能密度**：$w_m = \frac{1}{2} \frac{B^2}{\mu_0}$

**磁场能**：$W_m = \int_V w_m dV$

### 例题

**题1**：真空中一长直密绕螺线管通以电流$I$，管上单位长度绕$n$匝导线，内部的磁能密度为$w_m =$______

**解**：$B = \mu_0 nI$
$$w_m = \frac{1}{2} \frac{B^2}{\mu_0} = \frac{\mu_0 n^2 I^2}{2}$$

---

**题2**：真空中一根无限长直细导线上通电流$I$，则距导线垂直距离为$a$的空间某点处的磁能密度为（ ）

A. $\frac{1}{2} \mu_0 \left( \frac{\mu_0 I}{2\pi a} \right)^2$

B. $\frac{1}{2\mu_0} \left( \frac{\mu_0 I}{2\pi a} \right)^2$

C. $\frac{1}{2} \left( \frac{2\pi a}{\mu_0 I} \right)^2$

D. $\frac{1}{2\mu_0} \left( \frac{\mu_0 I}{2a} \right)^2$

**解**：$B = \frac{\mu_0 I}{2\pi a}$
$$w_m = \frac{1}{2} \frac{B^2}{\mu_0} = \frac{1}{2\mu_0} \left( \frac{\mu_0 I}{2\pi a} \right)^2$$

选**B**

## 1. 自感与互感

### 基本概念和公式

**自感**：
- 自感系数：$L = \frac{\Phi}{I}$
- 自感电动势：$\varepsilon = L \frac{dI}{dt}$

**互感**：
- 互感系数：$M = \frac{\Phi_2}{I_1} = \frac{\Phi_1}{I_2}$

![自感与互感公式](2.12自感与互感/2.png)

### 例题

**题1**：一无铁芯的长直螺线管，在保持其半径和总匝数不变的情况下，把螺线管拉长一些，则它的自感系数将（ ）

A. 增大 B. 减小 C. 不变 D. 不能确定

**解**：长直螺线管内的磁感应强度：$B = \mu_0 nI = \mu_0 \frac{N}{l} I$

磁通量：$\Phi = NBS = N \cdot \mu_0 \frac{N}{l} I \cdot \pi R^2 = \frac{\mu_0 N^2 I}{l} \pi R^2$

自感系数：$L = \frac{\Phi}{I} = \frac{\mu_0 N^2}{l} \pi R^2$

拉长后$l$增大，$L$减小。选**B**

![题1图示](2.12自感与互感/3.png)

---

**题2**：一自感线圈中，电流强度在0.002s内均匀地由10A增加到12A，此过程中线圈内自感电动势为400V，则线圈的自感系数为$L =$______$H$

**解**：由$\varepsilon = L \frac{dI}{dt}$：
$$400 = L \cdot \frac{12 - 10}{0.002} \Rightarrow L = 0.4 H$$

---

**题3**：一边长为$a$的正方形线圈放在一根长直导线旁，线圈与直导线共面。其中线圈的中心距长直导线为$\frac{3a}{2}$，线圈的一组对边与直导线平行。此时，正方形线圈与直导线的互感系数为（ ）

A. $\frac{\mu_0 a}{\pi} \ln 2$ B. $\frac{\mu_0 a}{2\pi} \ln 2$ C. $\frac{\mu_0}{2\pi} \ln 2$ D. $\frac{\mu_0}{\pi} \ln 2$

**解**：在$x$处取窄条，宽为$dx$

$$d\Phi = B \cdot dS = \frac{\mu_0 I}{2\pi x} \cdot adx = \frac{\mu_0 I a}{2\pi x} dx$$

$$\Phi = \int d\Phi = \int_{a}^{2a} \frac{\mu_0 I a}{2\pi x} dx = \frac{\mu_0 I a}{2\pi} \ln 2$$

$$M = \frac{\Phi_2}{I_1} = \frac{\frac{\mu_0 I a}{2\pi} \ln 2}{I} = \frac{\mu_0 a}{2\pi} \ln 2$$

选**B**

## 2. 麦克斯韦方程组

### 基本概念和公式

**1. 电场高斯定理** — 电场是有源场，电荷总伴随着电场
$$\oiint \vec{D} \cdot d\vec{S} = \sum q = \int_V \rho dV$$

**2. 磁场高斯定理** — 磁场是无源场，磁力线闭合
$$\oiint \vec{B} \cdot d\vec{S} = 0$$

**3. 变化的电场产生磁场**（全电流安培环路定理）
$$\oint \vec{H} \cdot d\vec{l} = I + I_d = \iint_S \vec{j} \cdot d\vec{S} + \iint_S \frac{\partial \vec{D}}{\partial t} \cdot d\vec{S}$$

**4. 变化的磁场一定伴随着电场**
$$\oint \vec{E} \cdot d\vec{l} = -\frac{d\Phi}{dt} = -\iint_S \frac{\partial \vec{B}}{\partial t} \cdot d\vec{S}$$

![麦克斯韦方程组](2.12自感与互感/5.png)

### 例题

**题1**：反应电磁场基本性质和规律的积分形式的麦克斯韦方程为：

A. $\oiint_S \vec{D} \cdot d\vec{S} = \int_V \rho dV$

B. $\oint_l \vec{E} \cdot d\vec{l} = -\iint_S \frac{\partial \vec{B}}{\partial t} \cdot d\vec{S}$

C. $\oiint_S \vec{B} \cdot d\vec{S} = 0$

D. $\oint_l \vec{H} \cdot d\vec{l} = \iint_S \left( \vec{j} + \frac{\partial \vec{D}}{\partial t} \right) d\vec{S}$

试判断下列结论是包含于或等效于哪一个麦克斯韦方程式：

(1) 变化的磁场一定伴随有电场：**B**

(2) 变化的电场产生磁场：**D**

(3) 磁场是无源场，磁力线闭合：**C**

(4) 电荷总伴随着电场：**A**
