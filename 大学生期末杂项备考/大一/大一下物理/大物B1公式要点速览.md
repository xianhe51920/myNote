## 01质点运动学（一）

| 公式名称 | 公式 | 备注 |
|----------|------|------|
| 位矢 | $\vec{r} = x\vec{i} + y\vec{j}$ | 位置矢量 |
| 位移 | $\Delta\vec{r} = \vec{r}_B - \vec{r}_A$ | 矢量差 |
| 平均速度 | $\vec{\bar{v}} = \frac{\Delta\vec{r}}{\Delta t}$ | 位移与时间比值 |
| 瞬时速度 | $\vec{v} = \frac{d\vec{r}}{dt} = \frac{dx}{dt}\vec{i} + \frac{dy}{dt}\vec{j}$ | 位矢对时间求导 |
| 速度大小 | $\|\vec{v}\| = \frac{ds}{dt} = \sqrt{\left(\frac{dx}{dt}\right)^2 + \left(\frac{dy}{dt}\right)^2}$ | 速率 |
| 加速度 | $\vec{a} = \frac{d\vec{v}}{dt} = \frac{dv}{dt}\vec{\tau} + \frac{v^2}{R}\vec{n}$ | 速度对时间求导 |
| 切向加速度 | $a_t = \frac{dv}{dt}$ | 改变速度大小 |
| 法向加速度 | $a_n = \frac{v^2}{R}$ | 改变速度方向 |
| 加速度大小 | $\|\vec{a}\| = \sqrt{\left(\frac{dv}{dt}\right)^2 + \left(\frac{v^2}{R}\right)^2}$ | 总加速度大小 |
| 相对速度 | $\vec{v}_{绝对} = \vec{v}_{牵连} + \vec{v}_{相对}$ | 相对运动关系 |
| 相对加速度 | $\vec{a}_{绝对} = \vec{a}_{牵连} + \vec{a}_{相对}$ | 相对加速度关系 |
| 匀变速直线运动（速度） | $v = v_0 + at$ | 速度公式 |
| 匀变速直线运动（位移） | $x = x_0 + v_0t + \frac{1}{2}at^2$ | 位移公式 |
| 匀变速直线运动（速度位移） | $v_2^2 - v_1^2 = 2a(x_2 - x_1)$ | 速度位移关系 |

## 02质点运动学（二）

| 公式名称 | 公式 | 备注 |
|----------|------|------|
| 角位移 | $\theta$ | 单位：rad |
| 角速度 | $\omega = \frac{d\theta}{dt}$ | 角位置对时间求导 |
| 角加速度 | $\beta = \frac{d\omega}{dt} = \frac{d^2\theta}{dt^2}$ | 角速度对时间求导 |
| 周期 | $T = \frac{2\pi}{\omega}$ | 转动一周时间 |
| 线速度与角速度 | $v = \omega R$ | 角量与线量关系 |
| 切向加速度与角加速度 | $a_t = \beta R$ | 角量与线量关系 |
| 法向加速度与角速度 | $a_n = \omega^2 R = \frac{v^2}{R}$ | 角量与线量关系 |
| 匀变速圆周运动（角速度） | $\omega = \omega_0 + \beta t$ | 角速度公式 |
| 匀变速圆周运动（角位移） | $\theta = \theta_0 + \omega_0t + \frac{1}{2}\beta t^2$ | 角位移公式 |
| 匀变速圆周运动（角速度角位移） | $\omega_2^2 - \omega_1^2 = 2\beta(\theta_2 - \theta_1)$ | 角速度角位移关系 |

## 03常见力和牛顿三定律

| 公式名称 | 公式 | 备注 |
|----------|------|------|
| 重力 | $G = mg$ | $g = 9.8N/kg$ |
| 弹力（胡克定律） | $F = kx$ | $k$为弹性系数 |
| 滑动摩擦力 | $f = \mu_k N$ | $\mu_k$为滑动摩擦系数 |
| 最大静摩擦力 | $f_{max} = \mu_s N$ | $\mu_s$为静摩擦系数 |
| 万有引力 | $F = G\frac{Mm}{r^2}$ | $G = 6.67 \times 10^{-11} N \cdot m^2/kg^2$ |
| 牛顿第二定律 | $\vec{F} = m\vec{a}$ | 力是产生加速度的原因 |

## 04动量,冲量,动量守恒

| 公式名称 | 公式 | 备注 |
|----------|------|------|
| 动量 | $\vec{p} = m\vec{v}$ | 单位：$kg \cdot m/s$ |
| 动量定理 | $\vec{I} = m\vec{v}_2 - m\vec{v}_1 = \int_{t_1}^{t_2} \vec{F}dt$ | 冲量等于动量变化 |
| 常力冲量 | $\vec{I} = \vec{F} \cdot \Delta t$ | 力为常量时 |
| 动量守恒定律 | $\sum m_i \vec{v}_{i1} = \sum m_i \vec{v}_{i2}$ | 条件：合外力为零 |

## 05质点运动的功和能

| 公式名称 | 公式 | 备注 |
|----------|------|------|
| 元功 | $dA = \vec{F} \cdot d\vec{r}$ | 力与位移点积 |
| 功 | $A = \int \vec{F} \cdot d\vec{r}$ | 元功积分 |
| 一维变力做功 | $A = \int_{x_1}^{x_2} F dx$ | $F = f(x)$时 |
| 恒力做功 | $A = \vec{F} \cdot \vec{r} = F_x x + F_y y + F_z z$ | 力为常量时 |
| 动能 | $E_k = \frac{1}{2}mv^2$ | 动能定义 |
| 动能定理 | $A = E_{k2} - E_{k1} = \frac{1}{2}mv_2^2 - \frac{1}{2}mv_1^2$ | 合外力做功等于动能增量 |
| 重力势能 | $E_p = mgh$ | 零势能点：地面 |
| 弹性势能 | $E_p = \frac{1}{2}kx^2$ | 零势能点：平衡位置 |
| 万有引力势能 | $E_p = -G\frac{Mm}{r}$ | 零势能点：无穷远 |
| 静电力势能 | $E_p = \frac{1}{4\pi\varepsilon_0}\frac{q_1q_2}{r}$ | 零势能点：无穷远 |
| 机械能 | $E = E_k + E_p$ | 动能+势能 |
| 机械能守恒 | $E_{k1} + E_{p1} = E_{k2} + E_{p2}$ | 条件：只有保守力做功 |

## 06电场强度

| 公式名称 | 公式 | 备注 |
|----------|------|------|
| 库仑定律 | $F = \frac{1}{4\pi\varepsilon_0} \cdot \frac{q \cdot q_0}{r^2}$ | 点电荷间作用力 |
| 真空介电常量 | $\varepsilon_0 = 8.85 \times 10^{-12}\ C^2/(N \cdot m^2)$ | 常量 |
| 电场强度定义 | $\vec{E} = \frac{\vec{F}}{q_0} = \frac{1}{4\pi\varepsilon_0} \cdot \frac{q}{r^2}$ | 单位正电荷受力 |
| 点电荷场强 | $E = \frac{1}{4\pi\varepsilon_0} \cdot \frac{q}{r^2}$ | 球对称分布 |
| 无限长均匀带电直线场强 | $E = \frac{\lambda}{2\pi\varepsilon_0 r}$ | $\lambda$为线密度 |
| 无限大均匀带电平面场强 | $E = \frac{\sigma}{2\varepsilon_0}$ | $\sigma$为面密度，与距离无关 |
| 均匀带电圆柱面场强 | $E = 0$（$r < R$）；$E = \frac{\lambda}{2\pi\varepsilon_0 r}$（$r > R$） | 高斯定理推导 |
| 均匀带电球体场强 | $E = \frac{qr}{4\pi\varepsilon_0 R^3}$（$r < R$）；$E = \frac{q}{4\pi\varepsilon_0 r^2}$（$r > R$） | 高斯定理推导 |
| 连续带电体场强 | $dE = \frac{1}{4\pi\varepsilon_0} \cdot \frac{dq}{r^2}$，$E = \int dE$ | 积分求解 |

|----------|------|------|

## 10电容器

| 公式名称 | 公式 | 备注 |
|----------|------|------|
| 电容定义 | $C = \frac{q}{U}$ | 单位：F（法拉） |
| 平行板电容器（真空） | $C = \frac{\varepsilon_0 S}{d}$ | $S$为极板面积，$d$为间距 |
| 平行板电容器（介质） | $C = \frac{\varepsilon_0 \varepsilon_r S}{d}$ | $\varepsilon_r$为相对介电常数 |

| 圆柱形电容器（介质） | $C = \frac{2\pi \varepsilon_0 \varepsilon_r l}{\ln R_B / R_A}$ | 含介质 |
| 球形电容器（真空） | $C = 4\pi \varepsilon_0 \frac{R_A R_B}{R_B - R_A}$ | 同心球壳 |
| 球形电容器（介质） | $C = 4\pi \varepsilon_0 \varepsilon_r \frac{R_A R_B}{R_B - R_A}$ | 含介质 |
| 孤立导体球电容（真空） | $C = 4\pi \varepsilon_0 R$ | 单个导体球 |
| 孤立导体球电容（介质） | $C = 4\pi \varepsilon_0 \varepsilon_r R$ | 含介质 |
| 电容器串联 | $\frac{1}{C} = \frac{1}{C_1} + \frac{1}{C_2}$ | 等效电容 |
| 电容器并联 | $C = C_1 + C_2$ | 等效电容 |
| 极板间场强 | $E = \frac{\sigma}{\varepsilon_0} = \frac{U}{d}$ | 电场与电压关系 |
| 极板间作用力 | $F = \frac{1}{2} E \cdot q$ | 极板相互作用 |
| 含介质电容 | $C = \varepsilon_r C_0$ | 电容增大$\varepsilon_r$倍 |
| 含介质场强 | $E = \frac{E_0}{\varepsilon_r}$ | 场强减小$\varepsilon_r$倍 |
| 介电常量关系 | $\varepsilon = \varepsilon_0 \cdot \varepsilon_r$ | 介电常量乘积 |
