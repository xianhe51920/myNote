## 4. Assumptions & Decisions

| 假设/决策 | 理由 |

| 一章一个处理轮次（共 2 轮），每轮内一次性 Read 该章所有 PNG | 控制单次输出体量，便于失败时回滚 |
| 章节 H2 标题 = 子文件夹名去掉前导序号 | SOP 第 1.3 节规定 |
| 第四章 H2 写为 `## 第四章 运算符` | 子文件夹名 `4.第四章 运算符` 去前缀后即此 |
| 第五章 H2 写为 `## 第五章 方法` | 子文件夹名 `5.第五章 方法` 去前缀后即此 |
| 二级目录 `04.第四章：运算符` / `05.第五章：方法` 不影响 H2 取名 | H2 由外层 `4.第四章 运算符` 决定 |
| 不在 md 表格内使用 HTML 颜色 | SOP 第 163 行明确禁用 |
| 不在 md 中写「整理完成」等元信息 | SOP 第 154 节禁用项 |
| 跳过明显的目录页、装饰页、纯标题页 | SOP 第 6.5 节 |
| 不重命名 / 移动 PNG 文件 | SOP 第 162 行 |
